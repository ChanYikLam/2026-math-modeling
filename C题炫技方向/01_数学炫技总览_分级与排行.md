# 01 数学炫技总览：分级地图、评分表与路线选择

> 本文件把 C 题能"炫"的数学招式**穷举成一张可挑选、可排期、可放弃的地图**。
> 每一条都给出：**数学内核 → 适用问 → 难度 → 耗时 → 加分 → 翻车风险 → 详述位置**。
>
> 选择原则：**先结构、后算法；先精确、后近似；先有基线、后有改进。**
> 本文件只做导航与评分，具体公式与实现见 `02`–`07`。

## 一、五层能力地图

```
L5 决策科学层   过程建模 · 风险偏好 · 多目标 · 机制设计
                 └ 电价随机过程、Copula、CVaR/DRO、鲁棒、定价权、滚动信息价值
                        ▲
L4 算法工程层   分解 · 热启动 · 最优性证书 · 复杂度与规模
                 └ Benders/L-shaped、滚动热启动、交叉求解器对拍、gap 报告
                        ▲
L3 不确定性层   信息结构 · 场景 · 非预期性 · 上中下界夹逼
                 └ 报童临界分位数、场景树、VoI、完美信息界、误差传播
                        ▲
L2 结构洞察层   对偶/水价值 · 阈值律 · 无关性分解 · 边际价值 · 互斥性
                 └ 全题最高性价比：把"算了个数"升级为"证明了最优决策的形式"
                        ▲
L1 基础正确层   线性化 · 单位时标 · 环状边界 · 弃光松弛 · 跨日状态
                 └ 不做会死，做了不加分；是所有炫技的地基
```

**关键判断**：L1 决定你能不能得奖，**L2 决定你能不能得高奖**，L3 决定区分度，
L4 是"看起来很专业"的背书，L5 是"锦上添花但要小心翻车"。
**永远不要在 L1 未闭环时跳到 L3 以上。**

**列含义**
- `难度`：1 = 半小时内可完成；5 = 需要专门推导与调试
- `耗时`：一名熟练队员的小时数（含调试与作图）

- `风险`：翻车后反而减分的可能性（低/中/高）

| **元启发式（GA/PSO/SA/ACO）作为主求解器** | 本题为 LP/（若加逻辑约束则为）MILP，可精确全局最优；元启发式慢、无最优性保证、且无法给出对偶信息 | 精确求解；若为展示"能处理非凸扩展"，仅做小规模对照并给 gap |
| **深度学习端到端预测光伏** | 附件 3 已给预报；题目不问预测；365 天样本不足以训练深度模型；且引入无法解释的黑箱 | 只做**预报误差的统计刻画**（分布、相关、校准），服务于优化 |
| **AHP / 熵权 / TOPSIS 全家桶** | 本题是纯优化，无多指标评价任务；硬塞评价模型会被判"题意理解错误" | 若要做决策建议，用**多目标 Pareto 前沿**替代 |
| **博弈论 / 多智能体**（除非明确作为推广） | 题目设定微网是价格接受者、单一决策者，无对手 | 若想讲市场，做"若微网有定价权"的**推广情景**并明确标注为扩展 |
| **数字孪生 / 碳交易 / 元宇宙包装** | 与题目无关的名词套壳，典型减分 | 删掉 |
| **SMOTE 等过采样** | 本题无分类任务 | 删掉 |
| **把常规预处理包装成创新** | 缺日期 ffill、单位换算不是创新 | 放进"数据预处理"节，不作为创新点 |
| **M-23 近似动态规划（无把握时）** | 状态离散与维度选择容易做错，且验证成本高；审计 `14` 判为 D 级 | 用 M-20 的**终端水价值**（LP 对偶估计）替代，足够覆盖主要收益 |
| **DRO / Wasserstein 鲁棒** | 与 CVaR/最坏场景对照重复，数学门槛高、验证困难；审计 `14` 判为 D 级 | 用最坏场景对照或 CVaR 表即可 |
| **Benders / L-shaped 分解** | 本题 LP 规模单机可直接精确求解，分解属负优化；审计 `14` 判为 D 级 | 直接 LP + 最优性证书（M-34） |

## 六、如何判断一个炫技点"做完了"

每一项都必须同时满足以下五条，否则只是"提过一句"：

| # | 检查 | 反例 |
|---|---|---|
| 1 | **有公式或定理陈述**，并标注编号、在正文被引用 | 只在文字里说"可以用对偶解释" |
| 2 | **有数值证据**，且与基线/对照放在同一表或同一图 | 只贴一个数 |
| 3 | **有消融或边界条件**，说明它何时失效 | 声称普遍适用 |
| 4 | **有单位与口径**，能由审计脚本复算 | 数字来源不明 |
| 5 | **在论文里有明确归属章节**，不是散落在各处 | 摘要提了正文没有 |

> 落地模板（可直接抄进论文的"模型创新"节）：
>
> **缺陷** → 基线的哪个假设不成立、残差/题意/数据哪里显示出来；
> **改动** → 引入什么，其数学作用是什么（写成公式）；
> **证据** → 相对基线改善多少（同一场景、同一轨迹、同一口径）；
> **代价** → 计算/数据/解释成本增加多少；
> **边界** → 当什么条件成立时该改动不再适用，退回什么方案。

详见 `08` §6 与 `10` §1。
