## 1. 论文 ① 李翔 — 运用聚类算法预测地区电网典型日负荷曲线

### 1.1 核心方法

| 方法 | 内容 |
|---|---|
| K-means 聚类 | 对历史日负荷曲线按"日类型（工作日/非工作日）+ 气象因素（温度、降水、湿度）"聚类，得到若干典型日负荷模式 |
| 数据预处理 | 归一化（min-max 对气象因素、除以峰值对负荷）、初始聚类中心优化（均值等距法）、最优聚类数确定 |
| 典型日预测 | 先判定待预测日属于哪一类（按气象参数最近邻），再取该类的聚类中心作为典型日曲线 |

### 1.2 与 C 题的匹配分析

| C 题需求 | 匹配度 | 说明 |
|---|---|---|
| Q2-Q4 的**场景削减** | ● | K-means 可直接用于将蒙特卡洛生成的数百条场景削减为 20-50 条代表性场景；论文中"最优聚类数确定"方法（肘部法则/轮廓系数）可复用 |
| Q2 的**预测信息结构** | ○ | 本题附件 1 已给典型日数据，不需要从历史数据中聚类典型日；但聚类思路可用于"按季节/天气分档"构造异质场景 |
| 数据预处理 | ● | 归一化、异常值处理的方法可直接用于附件 2/4 的预处理 |
| 负载预测 | ○ | 本题不需要预测负载（附件 2 已给实际值），故核心功能不直接适用 |

### 1.3 落地建议

- **可迁移**：K-means 场景削减模块（Q2/Q3 的场景削减步骤直接可用）
- **不建议**：将聚类做"典型日预测"作为论文贡献——本题已给典型日数据，做这个属于画蛇添足
- **论文中的角色**：在"场景生成与削减"小节中引用，说明削减方法的来源

## 2. 论文 ② 宁楠 — 基于动态C藤pair-Copula的电力系统动态经济调度场景协同优化算法

### 2.1 核心方法

| 方法 | 内容 |
|---|---|
| 动态 C-vine pair-Copula | 用二元 Copula 函数逐层合并构建高维联合分布；C-vine 结构适合存在一个"中心变量"与其余变量均有较强相关性的情形 |
| 三类时变 Copula | 时变 Gaussian Copula、时变 t-Copula、时变 Clayton Copula——参数随时间变化，捕捉相关结构的动态性 |
| 边缘分布估计 | 核密度估计 (KDE) 求各变量的边缘分布 |
| 最优 Copula 选择 | 用与经验 Copula 的欧氏距离最小来选每层的最优二元 Copula 族 |
| 场景生成 | 基于拟合的 Copula 模型做蒙特卡洛抽样，生成相依随机场景 |
| 多学科协同优化 | 将含场景的随机优化分解为"系统级 + 误差场景级"双层，循环交互求解 |

### 2.2 与 C 题的匹配分析

| C 题需求 | 匹配度 | 说明 |
|---|---|---|
| Q4 **电价-负荷-光伏联合建模** | ●●● | **直接命中**。C 题实测：电价-负荷 ρ=+0.508、电价-光伏 ρ=-0.343（日尺度）、负荷-光伏也有相关。本题创新点 4 明确要求"用 Copula 保留相关结构"。宁楠论文的 C-vine pair-Copula 框架可直接套用于三维联合建模 |
| Q4 **尾部风险刻画** | ●●● | 时变 t-Copula 的厚尾特性天然适合刻画"高峰既贵又缺"的尾部聚集风险；Clayton Copula 捕捉下尾依赖（低光伏与高电价同时出现） |
| Q2-Q3 **场景生成** | ●● | Copula 场景生成可直接替代独立抽样，保留时间相关性与变量间相关性；比简单蒙特卡洛更保真 |
| Q4 **相关性的尺度效应** | ●● | 论文中"边缘分布 → 条件分布 → 联合分布"的分解思路，可解释为何池化 ρ=+0.028（看似无关）而日聚合 ρ=-0.343（实为负相关） |

### 2.3 落地建议

- **核心迁移**：将 C-vine pair-Copula 用于 Q4 的"价格-负荷-光伏"三维联合场景生成
  - 根节点选"电价"（与其余两个变量相关性均较强）
  - 每层选最优 Copula 族（Gaussian / t / Clayton），用 AIC/BIC 或欧氏距离判定
  - 时变参数可按"时段"（上午/下午/夜间）分档估计
- **论文中的角色**：Q4 创新点 4 的方法论支柱；可在"数据预处理与特征分析"节展示 Copula 拟合结果，在 Q4 模型节展示联合场景生成
- **注意事项**：
  - 宁楠论文面向的是"多个新能源电场"的空间相关性，本题是"电价-负荷-光伏"的变量相关性——需将变量角色重新映射
  - 需同时保留**电价-负荷正相关**与**电价-光伏负相关**，不可只建模一对
  - 论文的多学科协同优化部分对本题价值不大（本题规模不需要那种级别的分解）

## 3. 论文 ③ 王泰强 — 基于电力期货与CVaR的新能源发电企业风险管理创新应用

### 3.1 核心方法

| 方法 | 内容 |
|---|---|
| CVaR 风险测度 | 条件风险价值（Conditional Value at Risk），度量在置信水平 α 下尾部损失的条件期望 |
| 收益函数构建 | 总收益 = 中长期合约收益 + 现货市场收益 - 发电成本；现货价格服从 GEV 分布，中标率服从 Beta 分布 |
| 蒙特卡洛场景 | 1000 组随机场景，每组计算收益，通过 Rockafellar-Uryasev 公式求解 CVaR |
| 分时段风险分析 | 对 24 个时段分别计算 VaR 和 CVaR，揭示风险的时段分化特征 |
| 双重不确定性 | 同时考虑电价不确定性与电量（出力）不确定性 |

### 3.2 与 C 题的匹配分析

| C 题需求 | 匹配度 | 说明 |
|---|---|---|
| Q4 **CVaR 风险度量** | ●●● | **直接命中**。C 题知识点解析明确将 CVaR 列为 Q4 创新点 3（"风险厌恶的 CVaR 有效前沿"）。王泰强论文的 CVaR 计算框架（Rockafellar-Uryasev 线性化）可直接移植 |
| Q4 **双重不确定性** | ●●● | 论文同时处理电价与电量的不确定性，与 Q4 的"价格风险 + 电量缺口风险"完全对应 |
| Q2 **5倍紧急购电的尾部风险** | ●● | CVaR 天然度量尾部损失——5 倍惩罚造成的"最坏 5% 情景下的平均损失"正是 CVaR 的定义 |
| Q2-Q4 **分时段风险评估** | ●● | 论文按时段计算 CVaR 的方法可直接用于分析"哪些时段的费用风险最大"，为论文提供精细化的风险画像 |
| Q3 **调整决策的风险考量** | ● | 可在 MPC 滚动框架中嵌入 CVaR 约束，使每个时域的决策不仅最小化期望费用，还控制尾部风险 |

### 3.3 落地建议

- **核心迁移**：
  1. 将 CVaR 加入 Q4 目标函数：$\min\ \mathbb{E}[\text{Cost}] + \lambda \cdot \text{CVaR}_\alpha(\text{Cost})$
  2. 用 Rockafellar-Uryasev 公式线性化（引入辅助变量 $\eta$ 和 $z_\omega \ge 0$），整个问题仍为 LP
  3. 扫描 $\lambda \in [0, \lambda_{\max}]$，画出**费用-风险有效前沿**——这是高水平论文的标准加分图
- **分时段风险画像**：对 Q2 的 334 天结果，按小时聚合计算 CVaR，画出"24 小时风险曲线"
  - 预期发现：上午 05-11 时（光伏高估 → 紧急购电）和晚间 18-20 时（高价 → 费用集中）的 CVaR 最高
- **论文中的角色**：Q4 创新点 3 的方法论来源；Q2 的补充分析（超越单一期望费用）
- **注意事项**：
  - 王泰强论文用的是 GEV + Beta 分布假设，本题应改用**经验分布**或**核密度估计**（附件 4 有 365 天数据，足以拟合）
  - 置信水平 α 建议取 0.95（与论文一致），并做 α = 0.90 / 0.95 / 0.99 的灵敏度

## 4. 论文 ④ 孙丰杰 — 电力大数据的信息价值密度评价与提升方法研究

### 4.1 核心方法

| 方法 | 内容 |
|---|---|
| 价值密度定义 | 从空间（内存占用）和时间（运行速率）两个维度定义数据价值密度指标，并计及挖掘结果误差 |
| 三层过滤机制 | ① 脏数据过滤（异常值/缺失值处理）② 改进 K-means 记录级"横向"过滤（多初始中心 + 多机组并行）③ FP-network 字段级"纵向"过滤（继承 FP-growth 优点，单次扫描） |
| 改进 K-means | 多初始聚类中心、多机组并行处理，解决传统 K-means 对初始中心敏感的问题 |
| FP-network | 从 FP-growth 扩展，支持字段维度的关联分析过滤 |

### 4.2 与 C 题的匹配分析

| C 题需求 | 匹配度 | 说明 |
|---|---|---|
| 数据预处理 | ● | "脏数据过滤"思路可用于附件 2/4 的质量检查（虽然实测无缺失无负值，但可做分布异常检测） |
| 场景削减 | ● | 改进 K-means（多初始中心）比标准 K-means 更稳健，可用于 Q2/Q3 的场景削减 |
| 特征选择/降维 | ○ | FP-network 的字段级过滤思想可用于"哪些时段/特征对费用影响最大"的分析，但本题 144 个时段已有明确物理结构，不需要额外的特征选择 |
| 信息价值分析 | ● | "价值密度"概念可类比到 Q3 的"信息价值 (VoI)"分析——每次预报更新带来的费用降低 = 该次预报的"信息价值密度" |

### 4.3 落地建议

- **可迁移**：改进 K-means（多初始中心）用于场景削减，比标准 K-means 更稳健
- **概念迁移**：将"价值密度"概念迁移到 Q3 的 VoI 分析中——定义"第 m 次预报的信息价值密度 = (G1费用 - G_m费用) / 该预报包含的信息比特数"
- **不建议**：将三层过滤机制作为论文贡献——本题数据质量已验证良好，做数据清洗不属于核心贡献
- **论文中的角色**：仅在"数据预处理"小节提及脏数据检查；场景削减方法可引用

## 5. 论文 ⑤ 谭慧娟 — 基于Benders分解法的城市输电网最大供电能力研究

### 5.1 核心方法

| 方法 | 内容 |
|---|---|
| Benders 分解 | 将复杂优化问题分解为"主问题"（原变量空间）和"子问题"（固定主问题变量后的校核问题），通过迭代交换 Benders 割来逼近最优 |
| 主-子问题结构 | 主问题：计算供电能力（优化）；子问题：校核 N-1 安全性与静态电压稳定（可行性） |
| 改进迭代策略 | 根据子问题潜在的关联性，减少单次循环需计算的子问题数量；提高线性化 Benders 割的反馈质量 |
| 结构分解式求解 | 将耦合约束解耦后分配给不同子问题，降低单次求解规模 |

### 5.2 与 C 题的匹配分析

| C 题需求 | 匹配度 | 说明 |
|---|---|---|
| Q2-Q3 **大规模场景式 LP 分解** | ●● | Benders 分解可将"全场景联合 LP"分解为"主问题（计划购电量，跨场景共享）+ 子问题（每个场景内的 recourse 调度）"——这正是两阶段随机规划的标准分解结构 |
| Q3 **多阶段分解** | ●● | 多阶段 MPC 中，每个决策时刻的优化可视为"主问题"，后续时域的 recourse 视为"子问题"；Benders 割可加速收敛 |
| Q4 **分布鲁棒分解** | ● | 结合论文 ⑥ 的 DRO 框架，Benders 分解可将"最坏情形期望"的外层 max 与内层 min 分离 |
| 跨日分解 | ●● | 334 天的跨日耦合只有 SOC 一个标量 → 天然可按日分解；Benders 的"主问题传递耦合变量、子问题独立求解"思路与之完全吻合 |

### 5.3 落地建议

- **核心迁移**：在 Q2 的整体场景式 LP 中使用 Benders 分解
  - 主问题：$\min \sum_t p_t E^{buy}_t + \sum_\omega \pi_\omega \theta_\omega$，其中 $\theta_\omega$ 是第二阶段的成本下界（Benders 割）
  - 子问题（每个场景 ω）：给定 $E^{buy}_t$，求解 recourse 调度（电池 + 紧急购电 + 弃光）
  - 每次子问题求解后生成一条 Benders 割加回主问题
- **工程价值**：当场景数 > 100 时，Benders 分解比直接求解整体 LP 快一个数量级
- **论文中的角色**：在"算法设计"小节说明分解策略；可画出"主-子问题迭代流程图"
- **注意事项**：
  - 本题的 recourse 子问题本身是 LP（电池调度 + 紧急购电），Benders 割为线性
  - 谭慧娟论文的 N-1 安全校核与本题无关，不要照搬
  - 若用逐日分解（推荐），Benders 分解的必要性降低（每天只有 721 个变量，直接求解即可）

## 6. 论文 ⑥ 俞昊东 — 求解含非离散分布的分布鲁棒多阶段线性随机规划的Benders分解-动态逼近方法

### 6.1 核心方法

| 方法 | 内容 |
|---|---|
| 分布鲁棒多阶段随机规划 (DRSP) | 期望算子被替换为"最坏情形期望"：$\sup_{P \in \mathcal{P}} \mathbb{E}_P[F(x,\xi)]$，其中模糊集 $\mathcal{P}$ 由矩约束给出 |
| Benders 分解 + 动态逼近 | 对各阶段的决策成本函数 (cost-to-go) 构建分段线性逼近，通过 Benders 割迭代更新 |
| 非离散分布处理 | 不依赖情景树/离散化，直接在连续分布族上求最坏情形——避免了"维度灾难" |
| 阶段独立假设 | 随机因素按阶段独立时，可将多阶段 DRSP 近似分解为一系列带锥约束的凸优化子问题 |
| 收敛性证明 | 基于变分分析构建新的收敛性框架，证明近似问题对原问题具有上图收敛性 |

### 6.2 与 C 题的匹配分析

| C 题需求 | 匹配度 | 说明 |
|---|---|---|
| Q3 **多阶段随机规划** | ●●● | **直接命中**。Q3 的 4 阶段 MPC（0:00/6:00/12:00/18:00）正是多阶段决策结构。俞昊东论文的"多阶段 + Benders 动态逼近"框架可直接套用 |
| Q4 **分布鲁棒优化** | ●●● | **直接命中**。Q4 的波动电价带来"分布不确定"——不知道电价的精确分布，只知道矩信息（均值、方差可由附件 4 估计）。论文的矩约束模糊集 + DRO 框架正是 Q4 创新点的高级选项 |
| Q3 **非预期性约束** | ●● | 论文严格处理了"决策只能依赖已观察到的信息"这一约束，与 Q3 的 MPC 滚动框架完全一致 |
| Q2-Q3 **成本函数逼近** | ●● | 动态逼近方法可为 MPC 的终端价值函数提供更好的近似（比硬终端约束更精确） |
| Q4 **价格-负荷联合风险** | ●● | DRO 框架天然考虑最坏情形，可刻画"高峰又贵又缺"的尾部风险聚集 |

### 6.3 落地建议

- **高阶迁移（创新点 3/5 的升级路径）**：
  1. 将 Q3 的 MPC 框架升级为"分布鲁棒 MPC"：
     - 模糊集 $\mathcal{P}$ 由附件 3 预报误差的样本均值和样本协方差构造（矩约束）
     - 每个决策时刻求解 $\min_{E^{buy}} \sup_{P \in \mathcal{P}} \mathbb{E}_P[\text{Cost}]$
  2. 用 Benders 动态逼近各阶段的 cost-to-go 函数：
     - 在每个决策节点维护一个分段线性下界
     - 每次滚动后追加 Benders 割
  3. 与"标准 MPC（期望费用）"和"CVaR-MPC"做三方对比，画出费用-鲁棒性权衡曲线
- **务实迁移（更推荐，风险更低）**：
  - 不直接实现完整的 DRO 框架（实现复杂度高），而是**借鉴其思想**：
    - 在 Q4 中用"盒式不确定集"（由误差分位数界定）做鲁棒优化对照
    - 画出"保守度-费用权衡曲线"——这正是论文 ⑥ 的核心贡献的工程简化版
- **论文中的角色**：Q4 创新点 3 或 5 的理论支撑；在"模型评价"中讨论 DRO 作为推广方向
- **注意事项**：

## 9. 各论文的关键公式与 C 题的对接点

### 9.1 论文 ② 的 pair-Copula 分解 → Q4 联合场景

$$
F(p, L, PV) = C_{p,L}\big(F_p(p), F_L(L)\big) \cdot C_{p,PV|p}\big(F_{PV|p}(PV|p), F_{L|p}(L|p)\big)
$$

- 根节点 = 电价 p（与 L 和 PV 均有较强相关）
- 第一层：电价-负荷的二元 Copula（Gaussian / t / Clayton 中选最优）
- 第二层：给定电价后，光伏-负荷的条件 Copula
- 时变参数：按"上午/下午/夜间"分档估计

### 9.2 论文 ③ 的 CVaR 线性化 → Q4 目标函数

$$
\min\ \mathbb{E}[\text{Cost}] + \lambda \cdot \text{CVaR}_\alpha(\text{Cost})
$$

Rockafellar-Uryasev 线性化：

$$
\text{CVaR}_\alpha = \min_\eta \left\{ \eta + \frac{1}{(1-\alpha)|\Omega|} \sum_\omega z_\omega \right\}
$$

$$
z_\omega \ge \text{Cost}_\omega - \eta, \quad z_\omega \ge 0
$$

→ 整个问题仍为 LP，可用 HiGHS 直接求解

### 9.3 论文 ⑤ 的 Benders 分解 → Q2 场景式 LP

主问题：

$$
\min \sum_t p_t E^{buy}_t + \theta
$$

$$
\theta \ge \sum_\omega \pi_\omega Q_\omega^{(k)} + \sum_t \mu_t^{(k)} (E^{buy}_t - E^{buy,(k)}_t) \quad \forall k
$$

子问题（每个场景 ω）：

$$
Q_\omega = \min \sum_t 5 p_t g_{\omega,t}
$$

$$
\text{s.t.}\quad E^{buy}_t + \widetilde{PV}_{\omega,t}\Delta t + P^d_{\omega,t}\Delta t + g_{\omega,t} = \tilde{L}_{\omega,t}\Delta t + P^c_{\omega,t}\Delta t + s_{\omega,t}\Delta t
$$

→ 每次子问题求解后生成一条 Benders 割加回主问题

### 9.4 论文 ⑥ 的矩约束模糊集 → Q4 DRO 简化版

$$
\mathcal{P} = \left\{ P : \mathbb{E}_P[\xi] = \hat{\mu},\ \mathbb{E}_P[(\xi-\hat{\mu})(\xi-\hat{\mu})^\top] \preceq \hat{\Sigma} \right\}
$$

其中 $\hat{\mu}, \hat{\Sigma}$ 由附件 4 的电价数据估计（按小时分档）。

简化版：用盒式不确定集 $\mathcal{U} = [\hat{\mu} - k\hat{\sigma}, \hat{\mu} + k\hat{\sigma}]$，扫描 $k$ 画保守度-费用曲线。
