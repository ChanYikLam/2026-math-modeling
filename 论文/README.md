## 2. 格式规范逐条落位表

> 左列是 `format2026.doc` 的条款原文要点，右列是本工程中**具体由哪一行代码保证**。

| 条款 | 要求 | 本工程的实现 | 验收方式 |
|---|---|---|---|
| 第一条 | A4；上下左右页边距 ≥2.5 cm；左侧装订 | `preamble.tex` 的 `\usepackage[a4paper,top=2.5cm,bottom=2.5cm,left=2.5cm,right=2.5cm]{geometry}` | 打印样张量边距 |
| 第二条 | 第 1 页承诺书、第 2 页编号专用页 | **本工程不生成这两页** | 纸质版由赛区模板单独打印装订 |
| 第三条 | 摘要页含标题与关键词、无需英文、原则上 ≤1 页；页码自摘要页起、页脚中部、阿拉伯数字连续 | `sections/00_abstract.tex` 用 `{\linespread{1.4}...}` 单独控版式；`\pagestyle{fancy}` + `\fancyfoot[C]{\thepage}`；不重置 `\pagenumbering` | `tools/check_paper.py` 自动核验"摘要恰 1 页、正文自第 2 页起" |
| 第四条 | 正文不要目录、≤30 页；附录页数不限、须与正文装订 | **全文不加载 `\tableofcontents`**；`main.tex` 中 `\label{pg:bodyend}` 供脚本核算正文页数 | `check_paper.py` 读 `build/main.aux` 自动核算并对照 30 页上限 |
| 第五条 | 附录须含支撑材料文件列表与**全部完整、可运行的源程序**；缺失或与论文不符可能取消评奖资格 | `sections/90_appendix.tex` 附录 A（文件列表）+ 附录 E（`\codefile` 原样引入 `code/` 下真实文件，**不用截图**） | `check_paper.py` 逐个核对 `code/` 下文件是否存在 |
| 第六条 | 摘要页、正文、附录任何地方不得出现身份信息 | 不设 `\author`；`\hypersetup{pdfauthor={},pdfcreator={}}`；`check_paper.py` 正则扫描校名/学院/队号/赛区/承诺书 | `check_paper.py` 自动扫描源码与 PDF 元数据 |
| 第七条 | 引用须列参考文献并在正文标注 | `sections/refs.tex` 手动 `thebibliography`（GB/T 7714 格式，不依赖 bibtex，中文不出乱码）；正文用 `\cite{...}` | 人工双向核对（脚本无法判断文献真伪） |
| 第八条 | 字号/字体/行距/颜色不做统一要求；赛区可提更高要求 | 12 pt（小四）、行距约 1.2 倍、一级标题三号黑体居中、二级四号黑体 | 向本赛区确认是否另有要求，必要时改 `preamble.tex` 的 `\linespread` |
| 第九条 | 电子版提交"参赛论文 + 支撑材料"两个文件 | `main.pdf` + 自行打包 `support.zip` | 确认两个文件都已上传 |
| 第十条 | 电子版与纸质版完全一致；**单文件 PDF/Word**；≤20 MB；**第一页必须为摘要页**，不放承诺书与编号页 | `main.tex` 的第一页就是摘要页；`build.sh` 编译后自动报告页数与文件大小 | `check_paper.py` 自动核验第 1 页为摘要页、正文未越到第 1 页、大小 ≤20 MB |
| 第十一条 | 支撑材料含全部可运行源程序等，压成一个 RAR/ZIP（≤20 MB）；**文件列表要写入论文附录**；不得含身份信息 | 附录 A 给出了与压缩包**逐项对应**的文件树 | 解包逐项对照 |
| 第十二/十三条 | 不符规范视为违反竞赛规则 | 见本文档 §6 提交前清单 | 三人各自独立打勾一遍 |

## 3. 写作宏速查（`preamble.tex` 定义）

### 3.1 必用：占位符与提示

```latex
最优购电费为 \ph 元。              % 渲染为红色【待计算】；严禁编造数字
储电量上限为 \ph[10800] 元。        % 也可写成 \ph[其他占位文字]
```

```latex
\begin{guideblock}
这里写"本节必须出现什么"的写作提示。定稿模式下整块自动消失。
\end{guideblock}

\note{行内短注，仅写作模式可见}
```

> `tools/check_paper.py` 会统计 `\ph` 数量：写作模式报"注意"，`--strict` 下报"失败"。
> **定稿前必须把 `\ph` 全部替换成真算出来的数字。**

### 3.2 口径框（8 个核心指标，全文唯一口径源）

```latex
\begin{caliber}{C-01}{无储能基线购电费}
\textbf{定义}\quad $C^{base}=\sum_t p_t\Delta t\max(L_t-PV_t,0)$；%
\textbf{数据}\quad 附件 2 当日实际值；%
\textbf{时段}\quad $t=1..144$，$\Delta t=1/6$ h；%
\textbf{单位}\quad 元（2 位小数）；%
\textbf{不含}\quad 储能充电成本、紧急购电、调整与违约费用；%
\textbf{对照}\quad 波动电价口径下为 \ph 元；%
\textbf{复算}\quad \texttt{audit.py::baseline\_cost(...)}
\end{caliber}
```

> 行末的 `%` 用于吃掉换行空格，让各项连成一个自然段（省页面）。
> 正文引用口径时用 `\calref{C-01}`（渲染为"口径 C-01"）。

### 3.3 创新五段式

```latex
\begin{innovation}{1}{基于对偶水价值的阈值型充放电策略}
\ip{缺陷} 基线方案在……上存在问题：……。
\ip{改动} 本文引入……，其数学作用是（式 (11)）。
\ip{证据} 在同一场景集上，相对基线……由 a 变为 b（改善 x%）。
\ip{代价} 计算量增加……；若代价超过收益，退回基线。
\ip{边界} 当……成立时该改动不再适用，此时应退回……。
\end{innovation}
```

### 3.4 证据编号

```latex
由对偶条件可得阈值律 \evid{C-Q1-02}。   % 写作模式渲染为紫色 (C-Q1-02)
```

### 3.5 插图（缺图不中断编译）

```latex
\begin{figure}[htbp]
  \centering
  \includefig[width=0.95\linewidth]{fig05_waterfall.pdf}
  \caption{对象 + 时间/空间范围 + 单位 + 样本量或情景数（四要素缺一不可）}
  \label{fig:waterfall}
\end{figure}
```

### 3.6 附录源码（原样引入真实文件，杜绝"附录代码 ≠ 跑出结果的代码"）

```latex
\codefile{model_q1.py}              % Python 高亮
\codefile[plain]{requirements.txt}  % 无高亮
```

## 4. 页数预算与如何调整

格式规范第四条给的是**硬上限 30 页**，且附录页数不限。本工程的分配：

| 部分 | 实测（定稿模式） | 上限 |
|---|---:|---:|
| 摘要页 | 1 | ≤1 |
| 正文（一～十章） | 27 | ≤30 |
| 参考文献 | 1 | — |
| 附录 A–H | 7 | 不限 |

**留出的 3 页余量用来容纳**：8 张真实矢量图（每张约 6 cm 高）与少量本队推导；若需更多页面，优先砍条件图（fig04/08/09）而不是压缩主干结果。

需要调整时按以下顺序改（都在 `preamble.tex`）：

1. **行距**：`\linespread{1.2}` —— 改成 1.3 / 1.5 每提高 0.1 约多 1.5～2 页；
2. **版心**：`geometry` 的四个边距 —— **不得小于 2.5 cm**；
3. **表格字号**：各表已用 `\footnotesize`；
4. **浮动体密度**：`\topfraction` 等 6 个参数已放宽，减少"半空页"。

> ⚠️ 每次调整后都要**重新用定稿模式编译**并跑 `tools/check_paper.py`，
> 确认正文仍 ≤30 页、摘要仍为 1 页。

## 5. 字体与可移植性说明

| 事项 | 说明 |
|---|---|
| 字体方案 | 用 ctex 的**默认 `fontset=auto`**：macOS 用宋体/黑体，Windows 用 SimSun/SimHei，Linux 用 Fandol。**不要写成 `fontset=fandol`**——实测在 macOS 上会导致中文**静默丢失**（PDF 里根本不嵌入中文字体）。 |
| 编译引擎 | 必须用 **XeLaTeX**（或 tectonic）。`ctexart` + `xeCJK` 需要 XeTeX 引擎。 |
| 代码清单里的中文 | `\lstset{basicstyle=\ttfamily\footnotesize\songti}` 中的 `\songti` 是关键：不加它，中文注释会用未嵌入的等宽中文字体，导致**中文丢失或字体不嵌入**。 |
| macOS 的一个已知现象 | 标题用的 STHeiti 由 xdvipdfmx 生成 ToUnicode 失败，**不影响显示与打印**，但复制标题文字会得到乱码（正文宋体正常可复制）。若在意，可在 `preamble.tex` 里把 `\heiti` 换成可嵌入的黑体字族。Windows 上无此问题。 |
| 参考文献 | 用手动 `thebibliography` 而非 `bibtex + gbt7714`：实测 `gbt7714` 走 bibtex 时**中文条目会整体丢失**，手动写法最稳。 |

## 7. 本工程已经替你做掉的事

- **合规层**：A4/边距/页码/无目录/摘要一页/身份信息/文件大小，全部落到代码并有脚本可验证；
- **结构层**：十个章节 + 参考文献 + 附录八项全部搭好，标题层级、编号、交叉引用可直接用；
- **两张必画的概念图**：决策时序图（含四个必须标注：两套数据用不同线型、18:00 预报跨 24:00、紧急购电在实时、四问差别旁注）与问题依赖图（每条箭头都标"提供什么"）；
- **模型骨架**：问题 1 的 LP 全式（目标 + 平衡 + SOC 递推 + 界 + 弃光 + 日周期）、充放互斥命题及其证明、对偶阈值律、无储能基线闭式；问题 2 的两阶段模型与报童推导；问题 3 的非预期性与分段线性凸成本线性化；问题 4 的两层电价与 CVaR 前沿——**公式都写好了，填数字即可**；
- **附录 G 的长推导**：对偶推导（平稳性条件逐条）与报童临界分位数推导，可直接使用；
- **防错机制**：占位符红字、缺图红框、缺源码红框、三种模式切换、自动合规自查。
