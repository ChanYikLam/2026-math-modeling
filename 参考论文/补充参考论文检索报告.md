## 1. 创新点 1（Q2）：报童型安全边际解析解

### 1.1 风电场与储能联合投标报童模型 ✓

- **标题**：Joint Bidding Decision of Wind Farms and Energy Storage Based on Newsvendor Model
- **作者**：Xinyue SUN, Jian LIU, Meng OU, Yanyan LIU
- **出处**：Journal of Systems Science and Information, 2022
- **来源**：[CNKI 页面](https://wap.cnki.net/touch/web/Journal/Article/JSSI202201004.html)

**核心方法**：把风储联合系统的投标量当作报童模型的订货量——投标过多则多出的电量按低价（或罚价）结算，投标过少则面临缺额惩罚。由缺货成本 $c_u$ 与过剩成本 $c_o$ 给出最优投标分位数 $F^*(q) = c_u/(c_u + c_o)$。

**迁移到 C 题（Q2）**：

| 报童模型要素 | C 题对应 |
|---|---|
| 订货量 $q$ | 计划购电量 $E^{buy}_t$ |
| 需求 $D$ | 实际净负荷（负载−光伏）分布 |
| 缺货成本 $c_u$ | 紧急购电溢价 $=(5-1)p = 4p$ |
| 过剩成本 $c_o$ | 多买电的机会成本（$p - p^{low} \approx 0.395$，或完全浪费时 $c_o = p$） |
| 最优服务水平 $F^*$ | 计划购电量应设在需求分布的 88.6 分位（即缺货概率约 11.4%） |

**引用建议**：在 Q2 的"报童解析近似"小节引用，作为"5 倍惩罚 → 安全边际"这一结论的文献依据；再与自己的数值解对照，形成"解析 + 数值"互证。

## 2. 创新点 2（Q3）：预报更新价值 (VoI) 量化

### 2.1 Cost-Oriented Prediction Intervals（成本导向预测区间）○

- **标题**：Cost-Oriented Prediction Intervals: On Bridging the Gap Between Forecasting and Decision
- **来源**：[检索页](https://m.zhangqiaokeyan.com/journal-foreign-detail/0704037170141.html)
- **核心思想**：预测区间不应只追求统计精度（覆盖率），而应**面向下游决策成本**优化——预测误差的方向与幅度如何映射为决策损失。正是 C 题 Q3 "是否需要更多预报"的量化框架。

**迁移到 C 题（Q3）**：
- C 题实测"上午高估 → 计划偏少 → 5 倍紧急购电；下午低估 → 计划偏多 → 0.5 倍违约金"正是"误差方向 → 决策成本"不对称的实例
- 可定义**成本加权误差指标**：$\text{CostErr} = \sum_t w_t |e_t|$，其中 $w_t$ 按时段取 5p 或 0.5p，比统一 MAE 更能解释"为什么上午的预报更值钱"

### 2.2 数据价值驱动的新能源电力系统优化运行方法研究 ○

- **标题**：数据价值驱动的新能源电力系统优化运行方法研究（博士论文）
- **来源**：[CNKI 页面](https://wap.cnki.net/touch/web/Dissertation/Article/11412-1023133456.nh.html)
- **核心思想**：把"数据/预报"作为优化运行的输入资产，量化其**边际价值**——新增数据源（如加密预报）对运行成本/收益的贡献。

**迁移到 C 题（Q3）**：直接支撑 VoI 三组对照实验（G1 仅 0:00 / G2 4 次/天 / G3 加密）的"边际收益递减曲线"设计。

### 2.3 Benefits of forecasting and energy storage in isolated grids ○

- **标题**：Benefits of forecasting and energy storage in isolated grids with large wind penetration – The case of São Vicente
- **来源**：[检索页](https://xueshu.baidu.com/usercenter/paper/show?paperid=7706e1dafb74bd57b53780959f2a27b0)
- **核心思想**：量化"预报精度提升 + 储能"对孤网运行成本的影响——预报改善的收益与储能容量存在替代关系。

**迁移到 C 题（Q3/Q4）**：支撑"预报改善的价值是否随储能存在而下降"的讨论（本题中储能摆幅仅能覆盖 15.3% 净负荷，替代关系有限，可作为对比结论）。

## 4. 创新点 4（Q4）：Copula 联合场景生成

### 4.1 基于核密度估计和 Copula 函数的风-光-荷联合场景生成 ✓（高匹配）

- **标题**：基于核密度估计和Copula函数的风-光-荷联合场景生成
- **作者**：崔丽敏, 马志远, 陈星, 刘祎芳, 张浩楠
- **出处**：煤炭经济研究，2026
- **来源**：[期刊页面](https://www.chinacaj.net/MTJN/202604/536120)

**核心方法**：
1. 核密度估计 (KDE) 拟合风、光、荷各自的**边缘分布**（不预设正态等参数形式）
2. Copula 函数建模**变量间相关性**
3. 蒙特卡洛抽样生成联合场景
4. 场景削减得到典型场景

**为什么高度匹配 C 题**：C 题 Q4 的实测数据表明——池化相关系数具有欺骗性（电价–光伏池化仅 +0.028，但日聚合 −0.343、去形状 −0.467），必须用**不依赖线性相关假设**的方法建模相依结构；KDE + Copula 正好满足。而且该论文的"风-光-荷"三元结构可直接映射为 C 题的"电价-负荷-光伏"三元结构。

**迁移三步**：
1. 对电价 $p$、负荷 $L$、光伏 $PV$ 分别做 KDE 边缘分布拟合（注意：池化 144×334 样本会平滑掉日周期结构，建议**按时段分档**拟合）
2. 选 Copula 族（Gaussian / t / Clayton）拟合二元相依结构，用 AIC 或经验 Copula 欧氏距离选优
3. 蒙特卡洛抽样 → 联合情景集 → 供 Q4 场景式随机优化使用

**与本地 ② 宁楠论文的分工**：宁楠论文给的是 C-vine pair-Copula 的**高维框架**（藤结构、时变参数）；本论文给的是 KDE + Copula 的**轻量实现**（三元、单层 Copula 即可）。竞赛中建议先实现本论文的轻量版，若时间充裕再升级到宁楠的藤结构。
