\section{模型评价与推广}\label{chap:eval}

\subsection{模型优点与创新}

\subsubsection{主要创新点}

每条创新按五段式写：\textbf{缺陷}\(\rightarrow\)\textbf{改动}（可写成公式）\(\rightarrow\)\textbf{证据}
（同一场景集、同一实际轨迹上的消融或对照）\(\rightarrow\)\textbf{代价}\(\rightarrow\)\textbf{边界}。

\begin{enumerate}[label=\textbf{创新 \arabic*.},leftmargin=4.2em]
  \item \textbf{报童型安全边际：把“该多买多少”写成临界分位数。}
    \emph{缺陷}：计划只能依据 \(0{:}00\) 预报，而缺口代价是正常电价的 5 倍、超购只白付电费，两侧成本
    不对称（\(5:1\)），按预测中心值下计划等价于假设预报无误差；实测逐槽缺货频率却达 \(8.55\%\)。
    \emph{改动}：对单槽超购—缺货权衡建立报童近似，\(c_o=p_t\)、\(c_u=4p_t\)，临界分位数 \(F^*=4/5\)
    （式~\eqref{eq:q2-newsvendor}）；实现上把安全边际写成“按情景缺口分位数超购”的第一阶段量。
    \emph{证据}：消融（表~\ref{tab:abl-q2} 的 E0 行）移除后总费用由 \(14\,264\,792.13\) 元升至
    \(17\,398\,559.68\) 元，紧急购电量增至 6.72 倍，\textbf{边际价值 \(3\,133\,767.55\) 元}。
    \emph{代价与边界}：每情景需解一次追索 LP，场景集须先固定存盘；单槽近似忽略跨槽耦合与终端条件，
    且储能本身即对冲工具，故只作\textbf{方向性近似与上下界}。
  \item \textbf{预报更新价值的量化：把“要不要加密预报”变成可判定阈值。}
    \emph{缺陷}：题面直接追问该问题，只答“建议引入更多”既不可证伪也无法决策。
    \emph{改动}：在同一固定场景集与同一实际轨迹上\textbf{只改变信息结构}，定义 \(\mathrm{VoI}(n)\)
    （式~\eqref{eq:q3-voi}），并给出完全信息上界与“已实现的可获得信息价值比例”。
    \emph{证据}：\(C(1)=14\,264\,792.13\to C(4)=13\,932\,402.95\) 元，完全信息上界
    \(13\,874\,340.39\) 元；\(\mathrm{VoI}(4)=2.33\%\)、已实现 \(85.1\%\)。
    \emph{代价与边界}：额外求解两组模型与四次决策的通信结算复杂度；成本侧未实测，只给“年化获取成本
    须低于 \(58\,062.56\) 元“的阈值。\textbf{必要限定}：本文的 \(C(n)\) 是\textbf{滚动策略在实付口径下的
    费用}（计划层未按“后续可调整”重优化），故该差额是信息价值的\emph{保守}估计，不是多阶段模型最优值
    之差（\S\ref{sec:q3-mpc}）。
  \item \textbf{波动电价下的联合情景与 CVaR 风险—费用前沿。}
    \emph{缺陷}：电价自身随机（区间 \([0.0076,1.7936]\)~元/\allowbreak kWh、残差组内标准差
    \(0.1238\)、一阶自相关
    \(0.8589\)）且与净需求正相关；独立抽样会生成“午间光伏大发同时电价高企”的不可能情景并低估尾部，
    只报期望费用也没有回答“波动”。\emph{改动}：两层结构（骨架 \(+\) 残差）加日净需求残差与日均电价的
    二维分层代表日；风险侧用 Rockafellar--Uryasev 线性化
    \(\min\mathbb{E}[C]+\lambda\mathrm{CVaR}_{0.95}\)（式~\eqref{eq:q4-cvar}）。
    \emph{证据}：情景的 \(\rho(p,\text{净负荷})=0.2597\) 对实际 \(0.2620\)、均值相对差 \(0.082\%\)、
    关键分位最大相对差 \(6.99\%\)；前沿与真实轨迹回测同向（\(\lambda=1\) 时期望 \(+0.99\%\)、
    CVaR \(-3.43\%\)、回测 \(+0.57\%\)）。\emph{代价与边界}：每个 \(\lambda\) 点需重解（共 11 点）；
    情景来自 334 天历史，不能外推机制突变。
  \item \textbf{把可证伪性写成实验：相依结构诊断与三向对照。}
    \emph{缺陷}：随机规划依赖情景集构造、报童依赖分布假设、CVaR 前沿依赖 \(\alpha\) 与 \(\lambda\)，
    只报一个最优值无法判断结论是模型的产物还是问题的性质。\emph{改动}：把每处依赖改成
    \textbf{可执行对照}——C 藤 pair-Copula 诊断相依结构（\ref{sec:vine}）、四种情景生成器的样本外
    回放、机会约束与盒式分布鲁棒的上下两侧对照、L 形分解这条独立数值路径复核最优值。
    \emph{证据}：电价—光伏尾相依 \(\lambda_U=\lambda_L=0.0479\)（\(t\) 族，\(\nu=3.23\)），而决策
    相关的“电价—预报残差”对近似独立（\(\tau=-0.0259\)）；四种生成器样本外费用极差 \(0.37\%\)；
    机会约束最优档（\(\beta=0.10\)）仍贵 \(0.52\%\)；盒式鲁棒最优档五项指标无一占优（费用高
    \(11.43\%\)）；两算法最大相对间隙 \(3.76\times10^{-15}\)。
    \emph{代价与边界}：新增四套实验代码，计算与实现量约为主模型的 1.5 倍；对照只回答“结论是否稳健”，
    不回答“哪个模型更接近真实”，故只把差异 \(>1\%\) 的项作为结论性证据。
\end{enumerate}

\subsubsection{模型优点}

\begin{itemize}
  \item \textbf{结构统一}：四问共用同一套物理骨架（式~\eqref{eq:q1-model}），差别只在信息结构与风险
        处理，每层新增贡献都可单独消融（表~\ref{tab:abl-q2}、表~\ref{tab:abl-q3} 共十一组对照）；
  \item \textbf{可解释}：对偶水价值与阈值律给出可解释的策略形式（\(\alpha_t\le\eta_c\nu_t\)
        充电、\(\alpha_t\ge\nu_t/\eta_d\) 放电，144 槽违反次数 0），使充放电时段可解释、可质疑；
  \item \textbf{可复算}：全部数值由脚本从原始附件重算，并通过原始可行性、最优性与费用独立复算三重
        检验，另有 L 形分解这条独立数值路径复核最优值（\appref{sec:verify-three-app}{D.1 三层验证与审计结论}）。
\end{itemize}

\textbf{结算口径声明。} 本文目标函数\textbf{只含电能量购电费用}，未计入容量补偿、辅助服务收益与绿电
环境价值，也未计入电池循环衰减与安全成本，故所得节约幅度应视为\textbf{储能电能量价值的保守下界}。
用户到户电价还含输配电费、系统运行费与政府性基金及附加，本文只优化第一项：附加费按电量比例收取等价于
对全部电价加同一常数，最优调度会因往返效率小于 1 而改变；按最大需量收取则更会实质性改变策略，须显式
建模后重解。故本文的节省幅度既不是储能项目投资可行性的结论，也不是全成本口径的收益。

\subsection{推广与结论}

\subsubsection{模型推广与临界条件}

模型在以下条件下成立，偏离时须重新校准而非直接套用。① \textbf{价格接受型}：电价外生给定；若储能或
微网规模足以影响出清价格，目标须引入价格对自身报价的响应，模型由 LP 变为带均衡约束的问题，阈值律与
安全边际结论都不能沿用。② \textbf{不外送}（假设 A1）：允许按同一电价售电时目标需增加售电收益项，
盈余处置量 \calref{C-06} 由“必要”变为“可选”，须重解。③ \textbf{单一储能}：推广到多储能或多微网协同后
状态维度随设备数增长，“逐日解耦”的代价须重新评估（本文为 \(1\,183\,394.34\) 元，\(9.68\%\)，
表~\ref{tab:abl-q3} 的 FY 行）。④ \textbf{价差足够大}：套利有利的条件是峰谷价比高于 \(1.2346\)
（式~\eqref{eq:ch1-arb}）；压到该阈值附近时模型退化为“以规避紧急购电为主”的保险型策略（容量降到
\(7\,200\)~kWh 时节省率由 \(26.90\%\) 降到 \(19.59\%\)，功率降到 \(1\,250\)~kW 时降到 \(16.41\%\)）。
⑤ \textbf{负载刚性}：若引入需求响应，式~\eqref{eq:q1-balance} 中的 \(L_t\) 变为决策量，阈值律须重新
推导，但“两阶段 \(+\) 安全边际”框架可沿用。⑥ \textbf{单一电能量结算}：容量补偿、辅助服务与绿电环境
价值难以同时兑现，收益\textbf{不可简单叠加}，计入后结论方向不变（当前口径为保守下界）但幅度须重算。

\subsubsection{结论与建议}

\textbf{逐问结论。} ① \textbf{问题 1}：最优全天购电费 \(35\,126.95\) 元（典型日），相对无储能基线
\(48\,052.05\) 元节省 \(26.90\%\)，充、放电量 \(20\,740.67\) 与 \(16\,799.94\)~kWh（比值 \(1.2346\)
与往返效率互为倒数），弃光为 0，最优策略由对偶水价值给出的两条阈值完全刻画。② \textbf{问题 2}：
334 天总费用 \(14\,264\,792.13\) 元（计划 \(13\,637\,552.90\) 元 \(+\) 紧急 \(627\,239.24\) 元），
紧急购电量 \(172\,015.82\)~kWh、出现在 296 天，节省 \(13.06\%\)；安全边际的边际价值
\(3\,133\,767.55\) 元，实测缺货频率 \(8.55\%\) 落在报童两条方向性参照之下侧；该问的紧急购电与盈余处置
两项量级由假设 A12（充放电冻结）决定，RT 消融给出其代价。③ \textbf{问题 3}：四次预报下滚动策略的
实付总费用降至 \(13\,932\,402.95\) 元（\textbf{策略评价，不是多阶段模型最优值}），相对只用 \(0{:}00\)
预报降 \(332\,389.18\) 元（\(2.33\%\)，依赖偏差量定价口径；“计划量全额结算 \(+\) 差额惩罚”读法下转为
\(-8.90\) 万元），已实现“完全信息”可省金额的
\(85.1\%\)，加密封顶的收益上限仅 \(58\,062.56\) 元（\(0.42\%\)），\textbf{故不建议继续加密预报时刻，
应把投入用于提高现有四次预报（尤其是上午）的精度}。④ \textbf{问题 4}：波动电价下两问费用为
\(15\,094\,255.84\) 与 \(14\,722\,153.17\) 元，节省 \(11.35\%\) 与 \(13.54\%\)；电价波动使费用上升
\(5.81\%/5.67\%\) 且不能由价格水平解释，说明\textbf{高价与高净负荷的共动}才是成本来源；风险可按
\(\lambda\) 调节，约 \(1\%\) 的期望费用溢价可换约 \(3.4\%\) 的尾部风险下降。主模型的价格信息取历史
代表日的层加权均值（假设 A10 的副口径为分时骨架）；负载条件化对照未改善实际回测，且全部费用均为
同窗口样本内评估。

\textbf{三条建议。} ① 预算有限时\textbf{优先扩容储能容量而不是加密预报}：容量档位的节省率区间为
\(19.59\%\)--\(42.56\%\)，远大于加密预报的上限 \(0.42\%\)，且容量摆幅是主要瓶颈（仅解除容量上限可再省
\(22.14\%\)，仅解除功率上限再省 \(1.66\%\)）。② 安全边际必须保留并\textbf{按目标整点配置}：边际价值
\(3\,133\,767.55\) 元，缺口集中在上午（\(5\)--\(11\) 时缺电频率最高 \(23.8\%\)、波动电价下
\(34.6\%\)），全天统一加成会同时浪费与漏配。③ 部署前按表~\ref{tab:limitation} 逐项校准效率、衰减、
负载预测与终端条件。上述结论只对“价格接受型、不外送、单一储能、以电能量购电费用最小”这一设定成立，
不构成储能项目的投资可行性结论。
