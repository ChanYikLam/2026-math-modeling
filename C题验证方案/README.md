# C 题《微网与外部电网电力调控策略》验证方案

> 本文件夹用于**验证建模思路、模型形式、求解结果与结论稳健性**，与 `C题知识点解析/` 互补：
> - `C题知识点解析/` 回答"怎么做、涉及哪些知识点"；
> - `C题验证方案/` 回答"怎么证明做对了、结论是否可信、哪些断言只是看起来对"。
>
> 本方案中的**参考基准值（Oracle）来自对附件 1–5 的独立复算**，可用于对拍；
> 正式提交前，队伍必须用自己的代码复现这些基准，不能直接引用为结果。

---

## 一、验证要回答的四个问题

| # | 问题 | 对应验证层 |
|---|---|---|
| V1 | 模型是否忠实刻画了物理与市场机制（信息结构、决策时序、约束）？ | 思路层（L1、L2） |
| V2 | 数学形式是否良定义、正确、可解（符号、单位、边界、凸性）？ | 模型层（L1、L2、L4） |
| V3 | 数值解是否是全局最优、是否可复现（残差、对偶、交叉求解器）？ | 解层（L3） |
| V4 | 结论是否稳健、是否有统计与样本外证据？ | 结论层（L4、L5） |

**核心原则**：求解器返回 `optimal` 只说明"这个模型被解出来了"，不等于"模型建对了"。

---

## 二、五级验证链条（总览）

```
L1 解析特例单测      先验知道答案，验证方向、单位、符号
        │
L2 合成数据端到端    已知 ground truth，验证结构与约束
        │
L3 真实数据独立审计  读回结果，独立复算物理量、费用、对偶
        │
L4 基线与消融        证明每个模块/创新的必要性与贡献
        │
L5 统计与稳健性      场景保真、样本外、配对检验、多种子、盈亏平衡
```

时间不足时的最低配置：**L3 审计 + L1 特例 + L4 基线与关键消融 + L5 泄漏测试与关键灵敏度**。

## 五、使用流程（建议）

1. 全队先读 `01` 与 `07`，确定验证分工与门禁；
2. 每问建模前，从 `02` 的 L1 特例开始写单测；
3. 每问出结果后，立即跑 `03` 对应清单 + `04` 审计与泄漏测试；
4. 全窗结果齐备后，跑 `05` 的统计与稳健性；
5. 提交前用 `06` 逐条自查，按 `07` 的红黄绿门禁放行。

## 六、与评审报告的关系

本方案修正并替代了知识点解析中被证伪的若干验证性断言，特别提醒：

- "问题 1 不设弃光不可行" **错误**（典型日最优弃光=0，无松弛也可行）；
- "预报误差随提前期增大 6h→24h 约 2.2 倍" **是样本构成造成的假象**，须改为同目标时段配对比较；
- "储能套利天花板 1.02–1.23 万元/日" **不可复现**，精确值为上表；
- 峰谷均价、附件 1 光伏相对偏差、"净负荷日均"口径等数字须按 `06` 修正后引用。

> 原则：**论文中出现的每一个数值，都必须能由审计脚本从原始附件重新算出。**
