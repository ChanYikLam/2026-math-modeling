## 0. 审计口径

### 0.1 什么叫"题目主干"

本题的"主干"分两层，两者不可混淆：

**第一层：题面主干（不可偏离的交付）**

| 问题 | 题面直接要求 | 必交成果 |
|---|---|---|
|  Q1  | 每天电价、负载相同；给出光伏一日预测；0:00 与 24:00 储电量相同；每天 0:00 制定当天计划 | 数学模型 + 表 1/表 2 格式结果 + `result1.xlsx` |
|  Q2  | 电价相同、负载与光伏逐日变化；缺电按交易时刻电价 **5 倍**紧急购电；每天 0:00 制定计划 | 计划/紧急购电策略 + 表 3 指定日期结果 + `result2.xlsx` |
|  Q3  | 0:00/6:00/12:00/18:00 可得未来 24 h 光伏预报；计划高于调整为 **0.5p** 违约、低于调整为 **1.5p** 超额；**必须分析是否需要引入其他时刻预报** | 计划/调整/紧急策略 + 指定日期结果 + `result3.xlsx` |
|  Q4  | 电价实时波动；在波动电价下**重新计算 Q2 与 Q3** | 两套结果 + `result4-2.xlsx`、`result4-3.xlsx` |
|  横切  | 附录参数（12000 kWh、5000 kW、6000 kWh、1200–10800 kWh、90%）；时标"0:00+1 = 当天 24:00"；正文 ≤30 页；摘要 ≤1 页；附录全部源码可运行 | 合规、可复现、无数据泄漏 |

**第二层：论文主干（回答四问的最小完整链）**

1. Q1：确定性 LP（目标 + 平衡 + SOC 递推 + 界 + 弃光 + 日周期）→ 数值解 + 对偶/策略解释 → `result1`；
2. Q2：信息结构声明（计划依据 ≠ 结算依据）→ 两阶段随机规划/场景 → 安全边际刻画 → `result2`；
3. Q3：多阶段滚动 + 非预期性 + 分段线性调整成本 → **用实验回答"是否需要更多预报"** → `result3`；
4. Q4：电价过程检验 → 两层建模 + 联合情景 → 重算 Q2/Q3 → `result4-2/4-3`；
5. 横切：时标与单位、跨日 SOC 与终端、费用口径完整、可行性/最优性/独立复算、结果文件与论文数字零差异。

> **判据**：一个炫技模块只有在"服务于以上任一条"时，才谈得上与题目主干关联；否则无论多高级，都是旁枝。

### 0.2 每个模块的判定四问

1. **关联**：它回答哪一问、哪一句题面？或支撑哪条主结论、哪项验证？
2. **必要**：不做会不会导致答案不完整、模型错误、验证缺口？还是只是"看起来更专业"？
3. **可验证**：本队是否有数据、代码和实验能给出证据？证据成本多大？如果只能引用文档中的"已复算"数字，则不可验证（违反 D1 数字纪律）。
4. **拥挤**：并入正文是否会挤掉主干内容、与已有章节重复、或诱发过度声称？正文只有 30 页硬上限。

**裁定规则**：若"关联弱 + 必要性低 + 拥挤高"三者占其二，就不并入正文；若"关联强 + 缺了会错/答不完整"，则无论多朴素都必须并入。

### 0.3 处置等级

| 级 | 含义 | 论文处置 |
|---|---|---|
| **S 主干刚需** | 缺了答案不完整，或模型/结论会错 | **必须并入正文对应节**；不能用"炫技"名义推迟 |
| **A 主干增益** | 直接强化主干结论或可信度，风险低、成本可控 | **压缩为 1 段 / 1 表 / 1 图择优并入**，建议选 6–8 项 |
| **B 条件并入** | 有价值但非刚需，需要证据或页面预算 | 有证据且不挤占主干 → 并入；否则降附录或不做 |
| **C 降级/附录** | 工程细节、背景分析、推广情景 | 不进正文；放附录、代码或"模型推广"一段 |
| **D 禁止并入** | 高风险、重复建设、负优化或过度声称 | 不写进论文；在文档中保留为"不要做"的反例 |

## 1. 结论摘要

### 1.1 数量结论

| 等级 | 数量 | 占比 | 说明 |
|---|---:|---:|---|
| S 主干刚需 | **11** | 26% | 已基本嵌入论文模板，重点是"把证据填实、把边界写准" |
| A 主干增益 | **10** | 24% | 择优压缩进正文；建议实际选 6–8 项 |
| B 条件并入 | **7** | 17% | 有时间且确有证据才做；默认不进正文 |
| C 降级/附录 | **11** | 26% | 只作为附录、代码工程或推广段素材 |
| D 禁止并入 | **3** | 7% | Benders、DRO、近似 DP；做了大概率减分 |

**与题目主干"直接相关"的比例约 50%（S+A = 21 项）**；但正文最多容纳 14–18 项。**其余 21 项应降级或放弃**。

### 1.2 三条必须先修的冲突（优先级高于任何炫技）

任何一条不修，炫技越多越自相矛盾。

| # | 冲突 | 现状 | 必须改成 |
|---|---|---|---|
| **X1** | **摘要的"容量瓶颈"表述与数据结论冲突** | 摘要写"储电量容量而非充放功率是收益瓶颈"；但 `02`/`06`/`09` 的复算结论是"**容量摆幅与充电功率同为紧约束，放电功率不紧**"（典型日充电功率打满 19/144，放电功率 0/144） | ① 完成容量/功率双向扫描，用 fig04 证据说话；② 摘要改为严谨表述（"容量摆幅与充电功率同时构成瓶颈"）；二者取一，不能只留原句 |
| **X2** | **阈值律适用范围** | `02` 自己已发现：完整 P1 中 \(E_t\) 无上界、\(B_t=0\) 绑定造成对偶退化，充电侧大量时段不能用简单阈值判定；精确刻画只在**纯套利子问题**成立 | 正文、图注、证据账本统一写限定："在纯套利子问题/界不活跃时成立；完整模型回退到互补松弛形式"；禁止在 Q1–Q4 无条件声称"阈值律=最优策略" |

> 这三条不是"炫技"问题，而是**判决一"这队读懂题了吗"的一级红线**（`11` 的 A3、D11、D12）。

### 1.3 结论性建议

1. **不新增独立章节**：42 个 M 项全部并入现有 Q1–Q4、数据、验证、评价各节；新增独立小节会直接挤爆 30 页。
2. **S 级先做**：即使只剩一半时间，也先把 11 个 S 项的证据补齐（它们多数已在模板中占好位置）。
3. **A 级择优**：按"是否直接强化本队主结论 + 是否已有代码产出"两条筛选，选 6–8 项；选不出的宁愿不做。
4. **B 级设门槛**：只有"证据已生成 + 不新增章节 + 能写进 1 图/1 表"的才并入。
5. **C/D 级不进正文**：Benders、DRO、近似 DP、场景缩减理论、Sobol 全套、Copula 全套、Pareto 前沿等，均不构成"答对题"的必要条件。

### 3.2 逐文件结论

- **`02` 是核心池，但必须减肥**：真正进正文的是"一条互斥命题 + 一个对偶/水价值定义 + 一条阈值命题 + 一个分解恒等式 + \(C^{base}\) 定义"；理想电池闭式、弃光影子价格、多日单 LP 技巧不构成答题得分点。`M-04` 只有在完成容量/功率双向扫描、并修正 X1 表述后才可进正文。

- **`04` 与题面关联度最高**：题面最后一问就是 VoI，非预期性是 Q3 的模型正确性，两者必进正文；终端水价值是 Q2–Q4 跨日模型的正确性保障，至少写进假设 A6 + 消融 B5；跨日 DP 与近似 DP 投入产出比极低，明确不做。

## 8. 一页结论（可直接贴群）

1. **主干已完整，炫技不需加章节**：四问模型链 + 验证链在论文模板中已经搭好，当前缺的是**真实数字与证据**，不是更多方法名。
2. **42 项只有 11 项是刚需**：对偶水价值、阈值律、充放互斥、\(C^{base}\)、报童、场景保真、VoI、非预期性、电价检验、最优性证书、假设审计。
3. **10 项值得压缩进正文**：无关性分解、边际价值（修 X1 后）、上下界夹逼、终端水价值、提前期配对、阈值普适性、风险对照、交叉对拍、相关三尺度、bias 方向。
4. **7 项设门槛**：安全边际曲线、场景缩减、CVaR 前沿、误差弹性、Copula、Sobol、提前期配对；有证据且不挤主干才做。
5. **14 项不进正文**：弃光影子价格、多日单 LP、理想电池、跨日 DP、鲁棒预算、Pareto、售电推广、热启动、规模表、校准检验、季节性检验、近似 DP、DRO、Benders。它们要么是工程细节，要么是过度设计。
6. **三条冲突优先级最高**：容量/功率瓶颈表述、阈值律适用范围、附件 1 身份与数据泄漏。这三条不修，炫技越多越扣分。
7. **执行顺序不可跳级**：P0（结果文件）> P1（四问正确）> P2（验证）> P3（写作骨架）> P4（S/A 核心）> P5（套餐 B）> P6（有条件）> P7（默认不做）。

> **最终判据**：任何一项炫技，如果回答不了"它让哪个结论更强、强到什么程度、拿什么证据说、代价与边界是什么"，就不合并。
