## 1. 物理系统与领域背景

```
                 ┌──────────── 外部电网（外网）────────────┐
                 │   分时/实时电价 p_t（买电，题目未给售电价）  │
                 └───────────────────┬─────────────────────┘
                                     │ 购电量 E_t^buy（决策）
        ┌────────────────────────────▼────────────────────────────┐
        │                      微网（非孤岛式）                     │
        │   ┌──────────┐   ┌──────────┐   ┌───────────────────┐   │
        │   │ 光伏 PV_t │   │ 储能电池  │   │  小区负载 L_t       │   │
        │   │ (不可控)  │   │ (可控充放) │   │  (刚性，必须满足)   │   │
        │   └──────────┘   └──────────┘   └───────────────────┘   │
        │        并网点功率平衡：买电 + 光伏 + 放电 ≥ 负载 + 充电      │
        └─────────────────────────────────────────────────────────┘
```

| 领域名词 | 含义 | 在本题的体现 |
|---|---|---|
| 微网 (microgrid) | 小型发用电系统，含分布式电源、储能、负荷 | 光伏 + 电池 + 小区负载 |
| 非孤岛式 / 并网 | 与外网保持连接，可买卖电 | 题目只要求"购电"，未提供售电价 |
| 分布式能源本地消纳 | 光伏就地被负载/储能吃掉，减少并网冲击 | 电池吸纳盈余，避免弃光 |
| 峰谷套利 | 低价时段充电、高价时段放电替代购电 | 四问的经济内核 |
| SOC / 储电量 | State of Charge，电池剩余电量 (kWh) | 1 200–10 800 kWh 约束 |
| 充放电效率 | 充/放过程中的能量损失 | 题给 90 % |
| 日前计划 / 实时调整 | 提前 1 天报量，日内滚动修正 | 问题 1、2 的"0:00 计划"；问题 3 的"计划+调整" |
| 紧急购电 / 违约 | 供能不足或偏离承诺的惩罚 | 5 倍电价；0.5 倍违约金 / 1.5 倍超额价 |
| 弃光 (curtailment) | 光伏盈余超出消纳与储能能力时被迫丢弃 | **必须设变量**（附件 2 实际日期序列上必需，72/334 天弃光 > 0；但全年平均日最优弃光 = 0，见 `README` 4.1） |

## 2. 逐问拆解

### 问题 1 — 典型日确定性计划购电

| 要素 | 内容 |
|---|---|
| **已知** | 全天电价 $p_t$；全天小区负载 $L_t$；全天光伏**预测**功率 $PV_t$（附件 1，10 min 粒度，144 点） |
| **未知/待定** | 各时段购电量、电池充放电量 |
| **决策变量** | $E_t^{buy}\ge0$（kWh）、$P_t^{c},P_t^{d}\ge0$（kW）、弃光 $s_t\ge0$ |
| **目标** | $\min \sum_t p_t E_t^{buy}$（全天购电费） |
| **硬约束** | ① 微网供能 **不得低于** 小区负载；② $S_{0:00}=S_{24:00}$（**日周期/环状约束**）；③ 电池 SOC∈[1200,10800]、功率 ≤5000 kW、效率 90 % |
| **交付物** | 论文表 1（指定 6 个 10-min 时段购电量 + 全天购电量/购电费）、表 2（6 个 4 h 时段充放电量 + 0:00 与 24:00 储电量）、`result1.xlsx` |
| **本质** | 确定性、单日、连续变量 **线性规划 (LP)** |

> **知识点抓手**："每天的电价和小区负载相同"= 把附件 1 当作**典型日**（实测确为年度逐时段均值）；
> "0:00 与 24:00 储电量相同"= **周期性边界条件**，把一天的调度闭合成环。

### 问题 2 — 固定电价 + 实际数据波动 + 紧急购电惩罚

| 要素 | 内容 |
|---|---|
| **已知** | 每天相同的电价（附件 1 的电价）；负载、光伏随时间变化（附件 2）；实际（结算）数据 |
| **新增机制** | 若微网供能 **低于** 负载 → 缺口必须**紧急购电**，价格 = 交易时刻电价的 **5 倍**；非紧急部分按计划购电量计价 |
| **决策变量** | 每天 0:00 制定的 144 个计划购电量；紧急购电量 $g_t\ge0$；充放电量 |
| **目标** | $\min \sum_t p_t E_t^{plan} + \sum_t 5p_t\,g_t$ |
| **交付物** | 表 1/表 2 格式给出 2025.3.20、6.21、9.23、12.21 的结果；表 3 给出紧急购电；`result2.xlsx`（计划购电量、充放电量、紧急购电量三个工作表；日期范围 **2025.2.1–12.31**，334 天） |
| **本质** | **两阶段随机规划 / 报童型（newsvendor）权衡**：买多了浪费（高价时段尤其），买少了被罚 5 倍 |

> **知识点抓手**：5 倍惩罚 → 最优"安全边际"由**临界分位数**决定：最优缺货概率为 $c_o/(c_u+c_o)$。
> 若过量购电完全浪费（$c_o=p$、$c_u=4p$）则为 **1/5**；若过量的电可存入电池在后续高价时段使用
> （$c_o\approx p-p^{low}$，约 0.37 元），则降至约 **1/10**（详见 `03` 第 3.2 节）。
> 表 3 特意选 **春分/夏至/秋分/冬至** 四个日期，暗示这四个"极端/转折日"应能呈现出紧急购电的差异。

### 问题 3 — 多次预报下的滚动调整

| 要素 | 内容 |
|---|---|
| **已知** | 附件 1 电价、附件 2 负载与光伏实际、**附件 3 的 4 次/天 24 h 光伏预报** |
| **新增机制** | 0:00 制定**计划购电量**；6:00/12:00/18:00 可依新预报制定**调整购电量**。计划 > 调整的差额付 **50 % 违约金**；调整 > 计划的超出部分按 **1.5 倍**电价付费。总费用 = 计划购电费 + 紧急购电费 + 调整相关费用 |
| **决策变量** | 计划量 $E^{plan}_{t}$；各调整时刻的调整量 $E^{adj,(m)}_{t}$；充放电量；紧急购电量 |
| **目标** | $\min \sum_t\!\big[\,c^{plan}+c^{adj}+c^{emg}\,\big]$，其中调整费用为**分段线性凸**函数 |
| **交付物** | 表 1/2/3 格式给出四个指定日期结果 + **"是否需要引入其他时刻预报"的分析**；`result3.xlsx`（计划购电量 / 调整购电量 / 充放电量 / 紧急购电量 四个工作表） |
| **本质** | **多阶段随机规划 / 模型预测控制 (MPC) 滚动时域优化** + **信息价值 (VoI) 分析** |

> **知识点抓手**：本题的"调整"是**对承诺量的修正**，成本函数为
> $c^{adj}=\begin{cases}0.5p\,(E^{plan}-E^{adj}), & E^{adj}<E^{plan}\\ 1.5p\,(E^{adj}-E^{plan}), & E^{adj}>E^{plan}\end{cases}$
> —— 关于 $E^{adj}$ **凸且分段线性**，用两个非负偏差变量即可线性化（见 `03` 第 4.1 节）。

### 问题 4 — 实时波动电价

| 要素 | 内容 |
|---|---|
| **已知** | 附件 2 负载/光伏实际、附件 3 光伏预报、**附件 4 波动电价** |
| **要求** | 针对**波动电价**建立购电策略模型；在波动电价下**重算问题 2 与问题 3** |
| **交付物** | `result4-2.xlsx`（对应问题 2）、`result4-3.xlsx`（对应问题 3），以及论文中的相应计算结果 |
| **本质** | 在问题 2、3 的框架上叠加**价格不确定性**：既有电量风险（供货缺口），又有**价格风险**（买贵了） |

> **知识点抓手**：电价随机化带来**双重不确定性**，并且电价与负载正相关（实测 ρ=+0.508），
> 意味着"高峰既贵又缺"——风险会在时间上聚集，简单的独立同分布假设会低估风险（应保留相关性）。

## 4. 时标语义与三个数据对齐陷阱（**最容易丢分的地方**）

### 陷阱 A：时间戳代表"区间起点"还是"区间终点"？

- 附件 1/2/4 的时刻是 `0:10, 0:20, …, 0:00+1`，共 144 个标记，恰好覆盖一天 144 个 10 min 区间 → **时标是"时段末端"**：第 $i$ 个数据点对应区间 $((i-1)\Delta t,\ i\Delta t]$，$\Delta t=\frac16$ h；
- **两套模板的末标签写法不同，必须分别记牢**：
  - `result1.xlsx` 的 `计划购电量` 是**竖表**（2 列 × 145 行 = 1 表头 + 144 数据行），**末行**标签 = **`0:00+1-0:10+1`**；
  - `result2/3/4-2/4-3.xlsx` 的 `计划购电量` / `调整购电量` 是**横表**（335 行 × 147 列 = 1 表头 + 334 天日期行；147 列 = 日期列 + 144 时段列 + 全天购电量 + 全天购电费），**末列**标签 = **`0:00-0:10+1`**（另有一处笔误：第 42 列写作 `7:0-7:10`；**不要去改模板**，只在论文口径说明中提及）；
  - 两者**都没有** `0:00-0:10` 这一格——这是同一处语义位移的两种写法，不是两个问题。

**统一裁定**（与 `C题写作需求/论文写作需求操作文档.md` §7.3 一致）：

- **观察**：144 个标签是 `0:10-0:20, 0:20-0:30, …, 23:50-0:00+1, 0:00-0:10+1`（竖表末行写 `0:00+1-0:10+1`），**没有** `0:00-0:10`，末标签还跨到次日 0:10；
- **两种读法**：
  - **(a) 标签直读**：第 $i$ 格 = 标签所示区间。此时本日 $[0{:}00,0{:}10)$ 无处安放，且末格落在次日；
  - **(b) 位置读法（推荐，与附件"时段末端"约定一致）**：144 格按顺序对应本日 144 个 10 min 槽，**无缝铺满** $[0{:}00,24{:}00)$，标签仅作显示；
- **操作要求**：
  1. 全队在 `C题代码/code/config.py` **锁定一种读法**，写进口径表与假设节；
  2. **不得修改模板标签**；
  3. **按位置写入**：第 $j+1$ 格 ← 槽 $j$ = $[j\cdot10\text{ min},(j+1)\cdot10\text{ min})$，**不得按标签重映射**；
  4. 论文表 1 的"10:00-10:10"取附件标签 `10:10` 那一格；
  5. 自检用"**全天购电量 = $\sum$144 格**"，并**另加**一条**独立复算**——整体位移一个槽时该求和自检**不可见**，必须靠"用附件价格序列复算全天购电费"或"抽查指定槽位"来挡住错位。

### 陷阱 B：kW 与 kWh —— 忘乘时间长度

附件给的是**功率 (kW)**，结果要求的是**电量 (kWh)**：

$$ E \;[\text{kWh}] \;=\; P\;[\text{kW}] \times \Delta t\;[\text{h}], \qquad \Delta t = \tfrac{10}{60}=\tfrac16\ \text{h} $$

- 附件 1 负载均值 4 626 kW → 全天电量 4 626 × 24 = **111 024 kWh**（不是 4 626 kWh）；
- 附件 3 的预报是**小时功率**，若与附件 2 的 10 min 数据比较，需先按小时聚合（$\div 6$ 平均或求和后 $\times 1$ h）。

### 陷阱 C：附件 3 的日期列稀疏 + 提前期错位

- 日期只在每天首行出现 → 必须 `ffill`，否则 3/4 的行没有日期；
- `预报k小时` 是 $[h_0+k-1,\ h_0+k)$（已用 2025-1-1 数据验证）→ **不是** $[h_0+k,\ h_0+k+1)$；
- 预报时刻 18:00 的 24 小时预报会**跨到次日**，日内可用小时只有 6 个；跨日部分在日内调度中不得当作当日数据使用（**数据泄漏**）。

## 5. 必须自己补齐的"信息结构"假设（**本题最大的建模争议点**）

题面只说"在每天 0:00 制定计划"，但**没有明说 0:00 时刻你究竟掌握什么信息**。这决定了问题 2 是否退化为问题 1。

### 5.1 三种可能的解读

| 解读 | 0:00 已知 | 实际结算依据 | 紧急购电 | 评价 |
|---|---|---|---|---|
| **R1 完美信息** | 当日 $L_t$、$PV_t$ 全体真值 | 同左 | **恒为 0** | 问题 2 退化为"逐日重复问题 1"，题设的 5 倍惩罚与表 3 失去意义 → **不推荐作为唯一方案** |
| **R2 典型日预报** | 附件 1 的负载/光伏（**每天相同**） | 附件 2 当日实际 | 大量 | 与"附件 1 列名为**光伏发电预测功率**"、"问题 2 只用附件 1 与附件 2"的表述最自洽，但预报质量被人为设得很差 |
| **R3 日前预报** | 附件 3 的 **0:00 预报**（光伏）+ 负载预测 | 附件 2 当日实际 | 中等 | **最符合工程实际**（问题 3 正是"4 次预报"的自然延伸），且实测预报误差 MAE≈668 kW 足以产生有意义的紧急购电 |

### 5.2 推荐处理（写进论文的"模型假设"节）

> **主方案（R3）**：问题 2 的日前光伏预测取附件 3 中 **0:00 发布的预报**；负载预测取附件 2 当日负载
> （或对其加 MAE 同量级的预测误差做情景分析）；实际结算均用附件 2 真值。
>
> **对照方案**：同时给出 R1（完美信息，紧急购电=0）与 R3 的结果对比表，用来**量化预测误差的成本**
> （这正是本问的核心价值），并说明 R1 是 R3 的下界。

**无论选哪种，都必须**：① 在假设节显式声明；② 说明"计划依据"与"结算依据"是两套数据；
③ 用 `04` 中的灵敏度分析检验结论对预测误差水平的稳健性。

### 5.3 同类待声明假设清单

| 编号 | 待声明假设 | 建议取值 | 影响 |
|---|---|---|---|
