# 01 行业背景与政策市场机制

> 本文件回答三个问题：**C 题所在的是一个什么行业？这个行业 2025—2026 年在发生什么？这些机制如何对应到题目的四问？**
> 所有政策均标注文号与发布时间，**引用前请以官方原文为准**（见 `04` 的引用清单与核对提示）。

---

## 1. 一句话定位：C 题落在"新型电力系统 + 电力市场化改革"的交汇点上

题目的物理对象是**并网型微网**（小区负载 + 分布式光伏 + 电化学储能 + 与外部电网的并网点），
做的事情是**用户侧的能量管理与购电决策**。在真实产业里，这类主体的官方名称有几种：

| 产业里的叫法 | 政策依据 | 与本题的关系 |
|---|---|---|
| 智能微电网 / 源网荷储一体化 | 《关于促进新能源消纳和调控的指导意见》（发改能源〔2025〕1360号） | 题目字面对象 |
| 工商业储能 / 用户侧储能 | 《新型储能规模化建设专项行动方案（2025—2027年）》 | 题目里的"储能设备" |
| 电力用户 / 售电公司代理用户 | 《电力中长期市场基本规则》（发改能源规〔2025〕1656号） | 题目里"向外网购电"的买方身份 |
| 虚拟电厂 / 负荷聚合商（VPP） | 《关于加快推进虚拟电厂发展的指导意见》（发改能源〔2025〕357号） | 题目未涉及，但是最自然的"模型推广"方向 |
| 零碳园区 / 绿电直连项目 | 发改环资〔2025〕910号、发改能源〔2025〕650号、发改能源〔2026〕688号 | 题目的"小区/园区"现实落地形态 |

**一句话**：C 题不是一道凭空编的应用题，它是**中国电力市场化改革进入"用户侧深度参与"阶段**的一个标准业务场景切片。

## 2. 2025—2026 年行业的三条主线（热点的时间坐标）

### 主线一：新能源"全面入市"——136 号文

- 2025 年 2 月，《关于深化新能源上网电价市场化改革 促进新能源高质量发展的通知》（**发改价格〔2025〕136号**）发布：
  新能源上网电量**全面进入电力市场**，上网电价由市场形成；同时**取消新能源项目强制配储**，
  延续近八年的行政性配储机制退场，并建立"新能源可持续发展价格结算机制（机制电价）"作为过渡保障。
- 行业后果（已在 2025—2026 年实际发生）：
  - 2025 年上半年出现"531 抢装潮"（政策切换前集中并网）；
  - 2026 年起，新能源机制电价差价结算费进入**系统运行费**科目，向用户侧传导；
  - 电源侧储能从"并网门票"转向"靠市场收益活着"，收益不确定性显著上升。

> **对 C 题的启示**：题目里"储能只靠低充高放赚价差"的设定，对应的正是**后 136 号文时代**的真实处境——
> 没有行政补贴兜底，一切收益来自市场价差。题目事实上把行业最难的账（价差能不能覆盖成本）交给你算。

### 主线二：现货市场"全面铺开"——从试点到连续运行

- 《电力现货市场基本规则（试行）》（**发改能源规〔2023〕1217号**）确立现货市场框架；
- 《电力现货连续运行地区市场建设指引》（**发改能源〔2025〕1171号**）鼓励新型储能等新型经营主体**"报量报价"参与现货竞争**；
- 首批 8 个试点（2017 年确定，山东在列）→ 山东 2021 年 12 月起长周期结算试运行 → 2025—2026 年多省转入连续运行。

**现货市场的价格形态（这是问题 4 的现实原型）**：

| 现象 | 产业事实 | 对应题目 |
|---|---|---|
| 午间低价 / 负电价 | 2025 年山东全年**负电价 1330 小时**，其中近一半集中在春季；3—5 月可再生能源发电量 +27%、需求 −12% | 附件 4 中"午间电价回落"的极端版本 |
| 鸭子曲线（duck curve） | 正午光伏大发压价、傍晚光伏退坡 + 负荷爬升推价 | 附件 4 的"夜间谷 / 午间回落 / 晚间尖峰" |
| 日内波动远大于分时电价表 | 现货 15 min / 5 min 出清，价格上下限受申报规则约束 | 问题 4 必须把电价当随机过程而不是固定曲线 |

### 主线三：调节资源的"价值重估"与用户侧成本重构

- 《电力辅助服务市场基本规则》（**发改能源规〔2025〕411号**）：按"**谁提供、谁获利，谁受益、谁承担**"健全调峰、调频、备用、爬坡等费用传导；
- 《关于完善发电侧容量电价机制的通知》（**发改价格〔2026〕114号**）：首次在国家层面建立**电网侧独立新型储能容量电价**机制，各省据此给予容量补偿（甘肃、吉林、新疆等快速跟进）；
- 结果是：**用户侧电费结构发生实质变化**——
  - **系统运行费**从 2023 年下半年设立时的全国均值约 **0.008 元/kWh**，
    经煤电容量电价回收（发改价格〔2023〕1501号，回收约 30%）升至约 **0.026—0.028 元/kWh**，
    到 2026 年起叠加 136 号文新能源差价 + 114 号文煤电回收比例提至不低于 50%（约 165 元/千瓦·年），
    跃升至约 **0.066 元/kWh**；
  - 2026 年 7 月全国系统运行费平均同比 **+93.8%**，14 个省份同比涨幅超 100%（安徽达 14.78 分/kWh，全国第一，同比 +118.3%）；
  - 出现"**跷跷板效应**"：现货电能量价格越低，系统运行费反而越高（新能源压价 → 调节成本上升）。

> **对 C 题最大的启示（也是最容易被忽略的加分点）**：
> 题目里的"**购电费用**"隐含地被当作"**电能量费**"。现实中电力用户的到户电价是四项之和：
> **电能量费 + 输配电费 + 系统运行费 + 政府性基金及附加**（外加线损）。
> 只优化第一项，结论可能被后三项反噬——这正好是一个能写进"模型推广与局限"的高质量论述，
> 也可以做成一个**扩展模型**（把系统运行费作为与用电量成正比的外生加价），用灵敏度说明结论是否稳健。

## 5. 把机制翻译成"题目语言"：一张对照表

| 现实机制 | 现实规则要点 | 题目中的对应物 |
|---|---|---|
| 中长期交易 | 年度/月度/多年期合约锁量锁价 | 题目未涉及（可作推广：部分电量长协） |
| 日前市场（Day-ahead） | 提前一天申报次日的量价，出清形成日前价格 | **问题 1/2/3 的"每天 0:00 制定计划购电策略"** |
| 实时市场 / 滚动调整 | 日内多次出清；日前与实时的偏差按实时价结算 | **问题 3 的 6:00/12:00/18:00 调整购电量** |
| 偏差考核 / 不平衡资金 | 实际与计划偏离要被考核或按惩罚价结算 | **问题 3 的 0.5 倍违约金 / 1.5 倍超额价** |
| 紧急购电 / 保供电价 | 缺电时高价购电（现货价格上限或应急调度） | **问题 2 的 5 倍电价紧急购电** |
| 容量补偿 / 容量电价 | 对可靠容量给予固定补偿（储能已有国家层面机制） | **题目未含**（储能只挣价差）→ 模型推广/评价中必须指出 |
| 辅助服务（调频、备用、爬坡） | 独立品种、单独结算，"谁受益谁承担" | **题目未含** → 现实收益的重要一块 |
| 分时电价 / 零售套餐 | 峰谷时段由政府划定，逐年调整 | 附件 1/4 的电价形态 |
| 功率预测准确率考核 | 新能源场站短期/超短期预测精度纳入考核 | **附件 3 预报 → 问题 3 的信息价值（VoI）** |
| 系统运行费 | 用户按用电量分摊，2026 年大幅上涨 | 题目"购电费用"口径之外的真实成本 |
| 需量电费 / 基本电费 | 大工业按最大需量计收，削峰可直接省钱 | 隐性的第二类收益，可作扩展目标项 |
| 绿电绿证 / 碳核算 | 绿电有环境价值，可交易、可抵碳 | 题目未含 → 价值实现推广方向 |

## 6. 一句话总结（可直接写进论文"问题背景"）

> 在"新能源全面入市 + 现货市场连续运行 + 调节资源价值重估"的背景下，
> 微网（用户侧）的核心命题已经从"能不能买到电"变成"**在电价与出力的双重不确定性下，如何用储能把购电成本压到最低，同时不因偏差被罚**"。
> 本题的四个问题，正是这条现实命题从**确定性 → 不确定性 → 多阶段信息更新 → 价格随机化**的完整递进。
