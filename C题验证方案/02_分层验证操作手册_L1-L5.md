## L1 解析特例单测

### L1-1 单位与量纲

| 测试 | 构造 | 期望 |
|---|---|---|
| kW→kWh | 功率全 1 kW，144 段 | 电量 = 24 kWh，不是 1 kWh 或 144 kWh |
| 价格缩放 | 所有电价 ×λ | 调度方案不变（最优决策对正的价格缩放不变），总费用 ×λ |
| 时间缩放 | Δt 从 10 min 改为 20 min（并相应改容量参数） | 电量与费用按比例变化，结构不变 |

### L1-2 退化情形

| 编号 | 构造 | 解析结果 |
|---|---|---|
| T1 | 单时段、PV=0、无电池 | 购电 = L，费用 = p·L·Δt |
| T2 | 单时段、PV≥L、无电池 | 购电 = 0，弃光 = (PV−L)Δt |
| T3 | 电池容量→0 | 退化为无储能基线：典型日 48 052 元 |
| T4 | 所有电价相同、无 PV | 电池不产生任何价值，费用 = p·ΣL·Δt |
| T5 | 两时段、容量/功率充裕、η_c=η_d=0.9 | 当且仅当 0.81·p_high > p_low 时充放循环有价值；阈值 1.2346 |
| T6 | 紧急倍数 κ→∞ | 计划购电量趋于需求分布上极端分位，紧急购电趋于 0 |
| T7 | 惩罚倍数 κ=1（紧急价=计划价） | 问题 2 退化为确定性等价，紧急购电无额外惩罚 |

### L1-3 报童解析对拍

- 过剩全浪费：缺货成本 c_u=4p，过剩成本 c_o=p → 最优缺货概率 1/5=20 %；
- 过剩可回收：c_o≈p−p_min≈0.37，c_u=4p≈3.2 → F\*=3.2/(3.2+0.37)=0.896，缺货概率≈10 %；
- **对拍方式**：用单时段独立需求数据求解数值 LP/期望模型，比较最优计划量所在分位。

### L1-4 互斥性与凸性

- 随机生成 10⁴ 组价格序列，求解 LP，检查 `P^c_t·P^d_t ≤ 1e−6`；
- 检查调整费用函数在 E_plan 两侧斜率由 0.5p 升到 1.5p（凸），线性化后最优解不会 u⁺、u⁻ 同时为正。

**L1 通过标准**：全部特例相对误差 ≤1e−6；退化情形可复现。

## L2 合成数据端到端

### L2-1 已知最优轨迹恢复

1. 构造 24 段价格（明显峰谷）、固定负载、固定 PV；
2. 手工设计一条满足 SOC 与功率约束的最优轨迹（例如 0–5 时充、8–10 时放……）；
3. 让完整 LP 求解，比较目标值与关键时段充放电量；
4. 通过标准：目标值一致（≤1e−6），关键时段决策一致。

### L2-2 两阶段小规模枚举对拍

1. 造 2 个情景（如高/低光伏），各概率 1/2；
2. 第一阶段候选购电量离散成网格，每个候选对每个情景解第二阶段 LP；
3. 枚举求最优，与两阶段模型/LDR 近似比较；
4. 通过标准：目标值差 ≤1 %，最优第一阶段决策落在同一网格点或相邻点。

### L2-3 多阶段/滚动对拍

1. 造 2 个决策时刻、2 个情景的微型问题；
2. 用情景树精确求解，与 MPC 近似比较；
3. 记录差距作为"MPC 次优性"的基准。

## L3 真实数据独立审计

> 关键：审计代码与建模代码**不得共用费用/平衡函数**；建议由不同成员编写。

### L3-1 物理一致性

| 检查项 | 公式 | 阈值 |
|---|---|---|
| 平衡残差 | E_t + PV_tΔt + P^d_tΔt − L_tΔt − P^c_tΔt − s_tΔt | max\|·\| ≤1e−6 kWh |
| SOC 递推 | S_{t+1} − S_t − η_c P^c_tΔt + P^d_tΔt/η_d | max\|·\| ≤1e−6 kWh |
| SOC 上下限 | S_t ∈ [1 200, 10 800] | 越界数 = 0 |
| 功率上下限 | P^c_t, P^d_t ∈ [0, 5 000] | 越界数 = 0 |
| 互斥性 | P^c_t·P^d_t | ≤1e−6 |
| 周期/终端 | 问题 1：S_0=S_144；问题 2–4：跨日衔接与终端下界 | 满足 |
| 非负性 | 所有电量、费用 | ≥0 |

### L3-2 费用复算

按题面口径独立重算：

- 问题 1：Σ p_t E_t；
- 问题 2：Σ p_t E^plan_t + Σ 5p_t g_t；
- 问题 3：计划费 + 紧急费 + 0.5p·max(E^plan−E^adj,0) + 1.5p·max(E^adj−E^plan,0)；
- 问题 4：同 2/3，价格换附件 4。

**阈值**：与求解器目标值相对误差 ≤1e−4；差异必须能解释（如取整误差）。

### L3-3 最优性证明

| 方法 | 做法 | 通过标准 |
|---|---|---|
| 对偶目标 | 读取 HiGHS/Gurobi 的对偶值，计算对偶目标 | 与原始目标相对差 ≤1e−6 |
| KKT 残差 | 检查互补松弛与驻点条件 | 残差 ≤1e−6 |
| 影子价格解释 | 充电时段应满足 p_t ≈ η_c μ_{t+1}；放电满足 μ_{t+1}/η_d ≈ p_t | 符号与量级合理 |
| 交叉求解器 | HiGHS 与 CBC/Gurobi 各解一遍 | 目标值差 ≤1e−6 |

### L3-4 结果文件回读

- 工作簿名、工作表名、列名、列顺序与模板一致；
- 日期范围 2025-02-01…2025-12-31，334 天；
- result2/3/4 的充放电量表需按 334 天扩展行数（模板只给示例），紧急购电表按事件动态生成；
- 读回后重算残差与费用，防止"写文件时错位"。

## L4 基线与消融

### L4-1 基线

| 编号 | 定义 | 典型日 / 窗口参考 |
|---|---|---|
| B1 | 无储能，直接购正净负荷 | 典型日 48 052 元；窗口固定价 1 640.7 万、波动价 1 702.7 万元 |
| B2 | 贪心：电价低于阈值充满、高于阈值放空 | 由队伍实现；应不优于优化解 |
| B3 | 完美信息下界：已知全天数据的最优 LP | 任意在线策略费用的下界 |
| B4 | 消融：移除模块 | 见下表 |

### L4-2 消融矩阵

| 模块 | 移除方式 | 预期影响 | 必须报告 |
|---|---|---|---|
| 弃光变量 | 强制 s_t=0 | 问题 2–4 部分时段不可行或费用上升；问题 1 无影响（最优弃光=0） | 可行性与费用差 |
| 终端 SOC 约束 | 去掉 S_T≥S_0 | 出现"末日掏空" | 期末 SOC 与费用差 |
| 调整机制 | 只允许 0:00 计划（Q3/Q4-3） | 费用上升、紧急购电增加 | Δ费用、Δ紧急电量 |
| 惩罚意识 | 两阶段 → 确定性等价 | 紧急购电与期望费用上升 | Δ费用 |
| 价格不确定性 | F2/F3 → F1 完美价格 | 费用（事后）下降，风险信息丢失 | 价格风险成本 |
| 相关性 | 独立抽样 → 联合情景 | 低估尾部风险 | 尾部费用差 |

**通过标准**：每个保留模块的移除都造成方向合理、可分辨的恶化；若某模块无差异，应在论文中说明其非必要或降级为敏感性分析。

## L5 统计与稳健性（详见 `05`）

| 测试 | 关键点 | 通过标准 |
|---|---|---|
| 场景保真度 | 均值、方差、分位数、ACF、跨时段相关 | 统计检验不拒绝；关键分位差 ≤5 % |
| 样本外回测 | 1–6 月拟合、7–12 月验证 | 费用与紧急购电无系统性反转 |
| 配对比较 | 固定同一批目标时段/样本 | 报告 n、配对差与 CI；禁止跨样本比较均值 |
| 多种子 | ≥20 个种子 | 报告均值 ±95 % CI |
| 参数灵敏度 | 效率、容量、惩罚、价格水平、终端条件 | 结论符号不变或给出临界点 |
| 盈亏平衡 | 求"储能无价值/调整不划算"的临界参数 | 给出临界值与解释 |
