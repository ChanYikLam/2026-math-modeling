## 一、一句话结论

> C 题不是一个虚构的应用题，而是**中国电力市场化改革进入"用户侧深度参与"阶段**的一个标准业务切片：
> 在**新能源全面入市（136 号文）、电力现货市场连续运行、储能"断奶"后必须自己挣价差**的背景下，
> 微网要做的事就是——**在电价与光伏出力的双重不确定性下，用储能最小化购电成本，同时不因偏差被罚**。
>
> 题目的四问，正是这条现实命题的四级台阶：
> **确定性优化 → 不确定性优化 → 多阶段信息更新 → 价格随机化**。

## 三、五条最该记住的行业结论（TL;DR）

1. **价差不是瓶颈，容量才是。** 实测谷峰比 **2.98**，远高于套利的盈亏平衡阈值 $1/(\eta_c\eta_d)\approx1.235$；
   但储能可用容量仅 9600 kWh，约为日净负荷（55542 kWh）的 17%。
   → 论文的题眼是"**容量分配**"，不是"找价差"。**（H1）**

2. **问题 2、3 的现实名字叫"日前报量 + 实时结算 + 偏差考核"。**
   5 倍紧急购电、0.5 倍违约金、1.5 倍超额价，就是市场规则强度的参数化。
   → 用这个对应关系写假设节，专业度立刻不同。**（H4）**

3. **问题 3 的灵魂是"预报精度值多少钱"，不是"多买几次预报"。**
   实测预报 MAE 随提前期由 6 h 的 306.7 kW 增至 24 h 的 668.0 kW（约 2.2 倍），且系统性低估 −144 kW。
   → 必须做 **VoI 边际分析**并用数字回答"是否需要增加预报频次"。**（H5）**

4. **本文只算了电能量收益，所以是储能价值的"保守下界"。**
   现实中储能还有容量电价（114 号文）、辅助服务、容量租赁，但**多为顺序出清、难以叠加**；
   同时用户到户电价还要叠加输配电费与**近年快速上涨的系统运行费**。
   → 把这句话写进"模型评价"，既是诚实，也是加分。**（H6 + H9）**

5. **弃光是物理必然，报告弃光量是专业性而非失败。**
   19.27% 的时段存在光伏盈余，241 个时段盈余功率 > 5000 kW，
   即使满功率充电每年仍需弃光约 16297 kWh。**（H11）**
