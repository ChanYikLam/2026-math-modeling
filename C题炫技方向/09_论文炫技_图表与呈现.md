## 0. 三条总规则

| 规则 | 说明 |
|---|---|
| **一图一论** | 一张图只证明一件事。证明两件事就拆成两张，或把次要信息移到图注 |
| **图注自洽** | 图注必须含：对象、时间/空间范围、单位、样本量或情景数。**图必须能脱离正文被读懂** |
| **不用默认样式** | 默认的 `plt.plot()` 配网格是"没画图"。**统一的配色、线型、字号**是免费的加分 |

> **审计后选图顺序（`14`）**：必留 `fig03`（对偶/最优性证书）与 `fig06`（VoI，直接回答题面最后一问）；主干证据图为 `fig05`（瀑布）、`fig07`（消融）、`fig10`（机制解释）；条件图为 `fig04`（边际价值）、`fig08`（风险前沿）、`fig09`（误差结构）。页数不足时按 **`fig09` → `fig04` → `fig08`** 的顺序砍，保留能直接支撑主干结论的图。

```
   5000┤  ███        ███   ← 充电（落在低价/盈余时段）
      0┤─────███████──────
  -5000┤              ███  ← 放电（落在高价时段）
        └────────────────────────────────►
        0     6     12    18    24
```

**必须标注**：
- 三个子图的**竖直对齐虚线**：把"光伏盈余时段""充电时刻""低价时段"用同几条竖线连起来，
  **让读者自己看出它们只是部分重合**（典型日仅 46.1% 的充电量落在 11–14 时盈余段）；
- SOC 曲线要**标出上下界**（1200/10800 kWh）与**起止值**（问题 1 应相等）；
- 图注写出机制解释（**必须与实测结构一致，不得写成"把午间盈余存到傍晚"**）：
  "Q1 典型日总充电量 20 740.7 kWh 中仅 **46.1%** 落在 11–14 时的光伏盈余段，
  总放电量 16 799.9 kWh 中仅 **36.6%** 落在 17–21 时的高价段；
  22–23 时、0 时、9–10 时同样在充电，而时段 19/20/21（18–21 时，价 1.274/1.348/1.265 元/kWh）
  **只放不充**（放电 1 520.4 / 4 259.7 / 2 859.9 kWh）。
  因此主机制是**面向价格的跨时段套利**，而不是"把午间盈余存到傍晚"。
  SOC 触上界 **21/144**、触下界 **8/144**，充电功率打满 **19/144**、放电功率打满 **0/144**，
  故结论是**容量摆幅与充电功率同为紧约束、放电功率不紧**
  ——**不得**写"SOC 全程未触及上下界，容量未饱和"。"

> **这张图的价值**：它把"最优解"变成"看起来合理的行为"。
> 若 SOC 全程贴在上界或下界不动，说明模型可能有问题——**这张图也是自检工具**。

## 9. 应该避免的图（浪费篇幅还减分）

| 避免 | 原因 | 替代 |
|---|---|---|
| **饼图** | 无法表达过程与变化 | 瀑布图 / 堆叠柱 |
| **3D 曲面图** | 几乎不可读 | 等高线图 / 热力图 |
| **双 Y 轴但量纲相同** | 制造虚假相关 | 单轴或归一化后同轴 |
| **多张只改标题的折线图** | 稀释论证密度 | 合并为子图，或改成热力图 |
| **没有基线的"效果图"** | 无法判断好坏 | 必须叠加基线 |
| **默认配色 + 满屏网格** | 看起来像草稿 | 用 §0.1 的统一样式 |
| **图注只有"图 3 结果"** | 无法独立阅读 | 图注含对象/范围/单位/样本 |
| **正文里复述图的所有坐标** | 浪费篇幅 | 只说"图上读出的结论" |
| **像素截图的表格** | 模糊、不可检索、显得不认真 | 用真表格 |
| **超过 6 个子图的一页** | 无法阅读 | 拆页或精选 |

## 10. 图的产出与命名规范（工程细节，但很显专业）

```
C题代码/figures/                  ← 论文正文图的矢量版；生成脚本在 C题代码/code/
├── fig01_timeline.pdf          # 决策时序图（矢量；TikZ，源文件 论文/figures/fig01_timeline.tex）
├── fig02_dependency.pdf        # 问题依赖图（TikZ，源文件 论文/figures/fig02_dependency.tex）
├── fig03_q1_dual_price.pdf     # 对偶/水价值 + 充放电
├── fig04_q1_marginal_value.pdf # 容量边际价值
├── fig05_waterfall.pdf         # 成本分解瀑布
├── fig06_voi_curve.pdf         # 信息价值边际递减
├── fig07_ablation_matrix.pdf   # 消融矩阵
├── fig08_risk_frontier.pdf     # CVaR 前沿
├── fig09_forecast_error.pdf    # 误差结构 2×2
└── fig10_strategy_mechanism.pdf# 策略机制解释
```

**规范**：
- **全部导出 PDF（矢量）**——位图在打印时会糊，且无法在 PDF 里检索文字；
- 生成脚本统一放在 `code/plot_fig03…fig10_*.py`——即 **8 个数据图脚本**
  （`plot_fig03_q1_dual_price.py`、`plot_fig04_q1_marginal_value.py`、`plot_fig05_waterfall.py`、
  `plot_fig06_voi_curve.py`、`plot_fig07_ablation_matrix.py`、`plot_fig08_risk_frontier.py`、
  `plot_fig09_forecast_error.py`、`plot_fig10_strategy_mechanism.py`），**每张图一个函数**，
  并在附录说明"图 x 由 `plot_figxx_*.py` 生成"；
  **图 1（决策时序图）与图 2（问题依赖图）是 TikZ，没有对应的 Python 脚本**
  （源文件 `论文/figures/fig01_timeline.tex`、`fig02_dependency.tex`）；
- **图注写在论文里，不写在图里**（图里只放必要标注），这样排版更灵活；
- 图中文字用中文时**必须指定中文字体**，否则会出现方框（见 §0.1 的 `font.sans-serif`）。

```python
# 统一保存函数，避免每次都写一堆参数（FIG_DIR 由 code/config.py 给出 = C题代码/figures/）
def save(fig, name):
    fig.savefig(f"{FIG_DIR}/{name}.pdf", format="pdf")
    fig.savefig(f"{FIG_DIR}/{name}.png", dpi=300)   # png 仅用于快速预览，不进论文
    plt.close(fig)
```

## 11. 自查清单

| # | 检查 | 不合格表现 |
|---|---|---|
| 1 | 每张图是否**只承担一个论证任务**，且能一句话说出 | 图里塞了三条不相干的信息 |
| 2 | 图注是否含**对象、范围、单位、样本量** | 图注只有"图 3 …" |
| 3 | 是否**全部为矢量图（PDF）** | 位图截图，打印发糊 |
| 4 | 配色是否**全篇语义一致** | 同一含义在不同图里颜色不同 |
| 5 | 是否有**对偶/阈值图**（本文件 #2） | 只画了结果折线，没画最优性证据 |
| 6 | 是否有**成本分解瀑布图** | 只报一个总费用 |
| 7 | 是否有**消融矩阵** | 声称创新但无消融证据 |
| 8 | 是否每张比较图都**叠加了基线** | 只有自己的曲线 |
| 9 | 风险前沿是否配了**真实轨迹回测** | 只有情景内指标 |
| 10 | 是否画了**策略机制解释图**，且 SOC 未全程贴界 | 只有数字表，没有行为图 |
| 11 | 是否避免了饼图、3D 图、无基线效果图 | 有以上之一 |
| 12 | 中文字体是否设置正确（无方框） | 图里出现 □□□ |
| 13 | 图的生成脚本是否在附录可查 | 图无法复现 |
| 14 | 正文是否**不复述坐标**，只讲结论 | 大段"从图中可见 X 轴从 0 到 24…" |
