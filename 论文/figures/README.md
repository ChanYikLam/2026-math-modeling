## 出图工程规范

- **全部导出矢量 PDF**，PNG 只用于预览、不进论文（位图打印发糊且不可检索）；
- 生成脚本统一放 `C题代码/code/plot_fig03..fig10_*.py`，**每张图一个函数**，
  脚本名 = `plot_` + 图文件名（去 `.pdf`），与上表**逐行对应**；
- **图注写在论文里**（`\caption{}`），不要写进图里；
- 图中中文必须指定中文字体，否则出现方框：
  ```python
  import matplotlib
  matplotlib.rcParams["font.sans-serif"] = ["SimHei", "Songti SC", "Arial Unicode MS", "DejaVu Sans"]
  matplotlib.rcParams["axes.unicode_minus"] = False
  ```
- 统一保存到 `C题代码/figures/`（经 `config.py` 的 `FIG_DIR` 取路径，**不要**写依赖当前工作目录的裸 `figures/`）：
  `fig.savefig(FIG_DIR / f"{name}.pdf", format="pdf", bbox_inches="tight")`；
- **配色语义全篇一致**（同一含义全文同色），建议：
  ```python
  C = {"load": "#3B6EA5", "pv": "#E8A33D", "net": "#6B6B6B", "price": "#C0392B",
       "soc": "#27AE60", "charge": "#2E86C1", "dischg": "#8E44AD",
       "base": "#95A5A6", "opt": "#C0392B", "water": "#16A085"}
  ```
  规则：`price` 永远红、`soc` 永远绿、基线永远浅灰。

## 缺图时会发生什么

图片不存在时，`\includefig{...}` 会在论文里画一个**红框占位**并注明文件名，
**编译不会中断**——这样写作期可以随时出 PDF 给别人看，不必等图。
`tools/check_paper.py` 会列出所有缺失的图文件名。

## 必须避免的画法

饼图、3D 曲面图、双 Y 轴但量纲相同、多张只改标题的折线图、
**没有基线的"效果图"**、默认配色 + 满屏网格、只有"图 3 结果"的图注、
像素截图的表格、一页超过 6 个子图。
