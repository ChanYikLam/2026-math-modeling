# 05 统计验证与稳健性

> 适用于问题 2–4 的情景生成、滚动回放、灵敏度分析与结论表述。
> 核心原则：**所有"A 优于 B"的结论必须配对、可复现、带区间。**

---

## 1. 场景生成保真度

### 1.1 必检指标

| 指标 | 方法 | 通过标准 |
|---|---|---|
| 均值 / 方差 | 情景集 vs 历史残差 | 相对差 ≤5 % |
| 分位数 | 5 %/25 %/50 %/75 %/95 % | 关键分位差 ≤5 %，尾部 ≤10 % |
| 自相关 | ACF(1)…ACF(6) | 差异 ≤0.1 |
| 跨时段相关 | 相邻 10 min 误差相关 | 保持正值；独立抽样会显著偏低 |
| 分布拟合 | KS/QQ（正态与经验分布） | 报告 p 值与厚尾情况 |
| 保真度-规模 | 削减前后均值/方差/分位 | 削减误差 ≤5 % |

### 1.2 时间相关性

- 逐时段独立抽样会**低估聚合时段（4 h）的误差**；
- 推荐 AR(1)、分块 bootstrap 或经验轨迹重采样；
- 必须对比"独立抽样 vs 相关抽样"的费用分布，量化尾部差异。

### 1.3 相关性（问题 4）

- 历史 ρ(p,L)=+0.508、ρ(p,PV)=+0.028；
- 生成情景后重新估计，差异 ≤0.05；
- 推荐**分块联合重采样（Bootstrap）为主，Copula 为条件对照**（审计 `14`：M-25 为 B 级）；必须与独立抽样对照，报告尾部费用差。

## 2. 配对比较规范

### 2.1 为什么必须配对

反例（来自知识点解析文档）：把不同发布时刻的白天 MAE 直接比较（0:00 的 n=4 437 vs 18:00 的 n=121），得出"提前期 6 h→24 h 误差 2.2 倍"——该做法无效（两侧目标整点集不同）。
**正确的受控比较**：因 $(h_0,k)\to(h_0+k-1)\bmod 24$，**lead 6/12/18/24 在四个发布时次上命中同一批目标整点**，可直接比 MAE → **2.01×（全样本 $501.08/249.35$，$n=35\,004$）/ 2.03×（白天 $953.52/469.18$）**；逐目标整点的"最长/最短 lead"比在 **1.00×–3.57×**。
**注意区分**：本文件下文引用的 **697.1 vs 540.7（=1.29）** 是**另一组**对比（0:00 时次 vs 12:00 时次在共同目标整点 12–18 时上，$\approx$ lead 16 h vs lead 4 h），**不能**当作"6 h→24 h"的替代值——`炫技方向/06` 与 `11` D5 的 2.01×/2.03× 才是该问题的受控答案。

### 2.2 规范

1. **同一目标**：比较的双方必须覆盖相同的时段/样本；
2. **同一实际轨迹**：策略回放用同一年的实际 L、PV、价格；
3. **配对差**：对每个样本计算 Δ = cost_A − cost_B，报告均值、标准误、95 % CI；
4. **检验**：正态近似或 Wilcoxon 符号秩检验；
5. **报告 n**：任何均值都要附样本量；
6. **禁止**：用不同样本的均值直接相减，或用总体平均掩盖分组差异。

### 2.3 适用场景

| 场景 | 配对方式 |
|---|---|
| 确定性等价 vs 两阶段 | 同一日期集合，配对日费用差 |
| R1/R2/R3 信息结构 | 同一实际轨迹 |
| G1/G2/G3 VoI | 同一实际轨迹与同一场景种子 |
| F1 vs F2 | 同一天，比较事前期望 vs 事后最优 |
| 模型 A vs 模型 B | 同一数据、同一参数、同一随机种子集 |

## 3. 样本外回测

### 3.1 协议

```
训练/拟合：2025-01-01 – 2025-06-30
验证/回测：2025-07-01 – 2025-12-31
（结果报告窗口为 2025-02-01 – 12-31，注意区分）
```

- 用训练期估计误差分布、价格过程、场景集；
- 用验证期实际数据回放策略；
- 报告验证期费用、紧急购电量、弃光电量、SOC 轨迹；
- 与同期训练期表现对比，检查是否系统性恶化。

### 3.2 通过标准

- 验证期与训练期的单位费用差在 95 % CI 内不出现方向反转；
- 紧急购电占比无数量级变化；
- 若显著恶化，检查过拟合与分布漂移。

### 3.3 禁止

- 全样本调参后再在全样本上"回测"；
- 用未来数据预处理（如全期均值标准化）；
- 用验证期结果反过来调参数后仍称"样本外"。

## 4. 多种子与置信区间

- 场景生成、随机回放至少 **20 个随机种子**；
- 报告：费用均值、标准差、95 % CI（t 分布或 bootstrap）；
- 关键指标（费用、紧急购电量、弃光、CVaR）都要给区间；
- 若不同种子的结论方向不一致，说明结论不稳，需扩大场景或修正模型。

### 5.2 盈亏平衡分析

- 求使"储能无增量价值"的价差/效率/惩罚临界值；

- 给出临界点及经济解释，比单纯多条曲线更有信息量。

## 6. 风险度量验证（问题 4）

- 目标：min E[Cost] + λ·CVaR_α(Cost)；
- Rockafellar–Uryasev 线性化：

```
CVaR_α = min_η { η + 1/((1−α)|Ω|) Σ_ω max(0, Cost_ω − η) }
```

- 验证点：
  1. λ=0 时应退化为纯期望费用；
  2. λ→∞ 时应趋近最小化最坏（或极高分位）费用；
  3. 费用—风险前沿单调：风险下降时期望费用上升；
  4. 与历史/样本外尾部费用对比，不优于下界。

## 7. 结果呈现规范

1. 所有费用给区间或至少给多种子均值；
2. 所有"A 优于 B"给配对差与显著性；
3. 所有统计量注明样本量、筛选条件（如"白天、实际>100 kW"）；
4. 口径（净负荷定义、计划费是否退还、效率归属）逐条声明；
5. 参考基准值（无储能、完美信息）必须同口径。
