# C 题《微网与外部电网电力调控策略》炫技方向总览

> 本文件夹回答一个问题：**在"稳、对、全"之外，怎么让评审在一堆结构雷同的论文里记住你这一篇。**
>
> 与前三个文件夹的分工：
> - `C题知识点解析/` 回答"怎么做、涉及哪些知识点"（**做得对**）；
> - `C题验证方案/` 回答"怎么证明做对了"（**信得过**）；
> - `C题行业热点与实务/` 回答"行业上怎么说才专业"（**说得像行家**）；
> - `C题炫技方向/`（本文件夹）回答"**哪些地方值得多花 2 小时，能让分数跳一档**"（**记得住**）。

**一句话立场**：C 题的炫技不是"上更深的算法"，而是**把一个已经能解出来的优化问题，讲出别人讲不出的结构和证据**。
本题的全部数据已在手、模型全部可精确求解（LP/MILP），因此**任何元启发式都是减分项**；
真正的加分点集中在 **① 数学结构洞察 ② 信息结构与不确定性 ③ 呈现与证据链** 三条线上。

## 一、先立规矩：什么算炫技，什么只是热闹

| 维度 | 真炫技 | 假炫技（减分） |
|---|---|---|
| 数学 | 能写出**别人没写的等价形式、对偶解释、阈值律、界** | 堆模型名称：把 LP 写成"改进遗传算法" |
| 算法 | 精确求解 + 最优性证书（gap/对偶/交叉验证） | 该用 LP 却跑 PSO/GA，且只跑一次 |
| 数据 | 从数据里挖出**结构性结论**（如"相关系数有尺度依赖，池化值会误导建模"） | 只做描述统计，抄一遍均值方差 |
| 创新 | 有基线、有消融、有边界条件的"缺陷—改动—证据—代价—边界"五段式 | 声称"显著提升"却无对照 |
| 论文 | 一页让人看懂"四问是一条信息结构递进链" | 四问写成四篇互不相干的报告 |
| 图表 | 一张图独立承担一个论证任务 | 十几张折线图只改标题 |
| 附录 | 代码可运行、可复现、有随机种子 | 附录贴一堆截图或空壳函数 |

> **判据**：任何一项"炫技"，你必须能回答——**它让哪个结论变得更强？强到什么程度？拿什么证据说？**
> 答不上来的，删掉。**炫技的失败模式不是不够花哨，而是花哨但空。**

## 五、五个最容易踩空的炫技误区（先看这条，再动手）

| 误区 | 为什么是坑 | 正确做法 |
|---|---|---|
| **为了"高级"把 LP 换成启发式** | 本题 LP/MILP 可精确全局最优；启发式既慢又无最优性保证，评审直接判"方法选择错误" | 精确优先；启发式只用于对照或超大规模，且必须给 gap |
| **报童模型直接套用** | 本题是多时段 + 储能跨期耦合，纯报童只在"单时段、无储能、过剩全浪费"时严格成立 | 用作**近似刻画 + 上/下界 + 直觉解释**，并明确写出适用条件与偏差来源（见 `03` §1.4） |
| **CVaR/鲁棒与随机规划一起上但不做对照** | 三个模型给出三个数却说不清差异来源，属于"并列堆砌" | 固定同一场景集与同一实际轨迹，报告**相对差值**，并说明各自适用偏好（见 `03` §4、§5） |
| **宣称"引入深度学习预测"** | 附件 3 已提供预报，样本仅 365 天，且题目不问预测 | 若要做，限定为"预报误差模型"的统计刻画（分布/协方差），而非端到端深度预测 |
| **图表很多但每张只讲半句** | 篇幅（正文 ≤30 页）是硬约束，冗余图表反而稀释论证 | 一图一论；图注自带对象/范围/单位/样本（见 `09` §7） |

### 6.1 复算中修正的四处关键结论（**最易出错，务必先看**）

| # | 常见错误认识 | 复算后的事实 | 详见 |
|---|---|---|---|
| 1 | "电价与负载强相关（0.51）"即可支撑建模 | 相关系数**有尺度依赖**：池化 **0.508** / 日级 **0.898** / 剔除日内形状后 **0.797**。电价—光伏更极端：池化 **+0.028（看似无关）**，但日级 **−0.343**、去形状后 **−0.467**（**实为负相关**） | `06` §1 |
| 2 | "误差随提前期增大（2.2×）是样本构成假象" | **该批评只对"单个时次内部"成立**。跨时次的**同目标整点配对比较**中效应**为真**：**2.01×**（全样本）/ **2.03×**（白天），但倍数随目标整点从 **1.00×** 到 **3.57×** 剧烈变化 | `06` §2 |
| 3 | "弃光是结构性必需的结果，不设弃光变量不可行" | 弃光**变量**必需（保证极端日可行），但**平均日最优弃光 = 0**：日内盈余仅约 6 248 kWh、峰值盈余功率仅约 2 118 kW，**均低于**可用容量摆幅与充电上限，约束**非紧**（允许/禁止弃光两模型最优值一致） | `02` §6.0 |
| 4 | "阈值律 = 存在全天统一电价阈值" | 水价值 $\mu_t$ **分段常数、全天 13 个取值、范围 [0.4711, 1.2060]**，故阈值**时变**；且定理在**纯套利子问题**上精确成立（四条互补松弛 100%、恒等式偏差 ≤2.2e−16），完整 P1 的对偶结构不同 | `02` §3.1、§3.1c |

### 6.2 三个"代码能跑但结果错"的陷阱（本次实现中真实踩到）

| 陷阱 | 症状 | 正确做法 |
|---|---|---|
| **单位口径混用**：目标用 $p_t\Delta t$，功率界却写 $\overline P$（或反之） | 🔴 **求解器不报错**，只给"看起来合理"的错误值（本次算成 5 854 元而非 35 127 元） | 锁定一种口径全局贯彻。若变量为**电量 kWh**：目标系数 $p_t$、功率界 $\overline P\Delta t=833.33$ kWh（`13` §3、`11` C1b） |
| **充放电效率方向写反**：$S_t=S_{t-1}+\eta_cc_t-\eta_dd_t$ | 🔴 充放比变成 0.9 而非 $\eta_c\eta_d=0.81$，套利收益与容量核算全部失真，**LP 仍求解成功** | 正确：$S_t=S_{t-1}+\eta_cc_t-\dfrac{d_t}{\eta_d}$（放电效率在**分母**），并用"充放比 = 0.81"断言自检（`11` C1c） |
| **对偶符号/相位靠猜** | 🔴 阈值公式"看起来对"但与数值解不符 | ① 用最小算例标定符号；② 用 KKT 恒等式 $z^c_t=p_t-\eta_c\mu_t$、$z^d_t=-p_t+\mu_t/\eta_d$ 反推（应精确到 $10^{-16}$）；③ 断言"可改进方向数 = 0"（`02` §3.5、`13` §3） |
