## 二、关键公式与推导要点（保留原符号与单位）

### 2.1 统一符号与口径（先登记再写公式）

- 集合：t∈T，|T|=144（10 min），Δt=10/60=1/6 h；d∈D=2025-02-01…12-31，|D|=334；m∈M={0,6,12,18}（小时）；ω∈Ω，概率 π_ω（03_数学模型与算法知识点.md:12-17）。
- 参数：L_{d,t}、PV_{d,t}（kW，附件 2）；\widehat{PV}^{(m)}_{d,h}（kW，附件 3）；p_{d,t}（元/kWh，附件 1 固定价 / 附件 4 波动价）；η_c=η_d=0.9；\underline S=1200、\overline S=10800、S_max=12000 kWh；\overline P=5000 kW；S^init=6000 kWh @2025-01-01 0:00；κ_emg=5；κ^+=1.5、κ^−=0.5（03_数学模型与算法知识点.md:21-33）。
- 决策：E^buy（计划购电量，kWh）、E^adj（调整购电量）、g（紧急购电量）、P^c/P^d（充/放功率，kW；模板改写成电量量 c_t,d_t，kWh）、s（弃光）、S_t（时段末储电量）（03_数学模型与算法知识点.md:37-44）。
- 单位纪律：kW × 1/6 h = kWh；模板采**电量口径**，目标系数 p_t 不再乘 Δt，充放上限 = \overline P Δt = 833.33 kWh（04_q1.tex:16-19, 24-25）——与 03 的功率口径 P^c_t 并存，**不可混用**（03_数学模型与算法知识点.md:130）。

### 2.2 问题 1：确定性单日 LP

- 目标：min_{E,c,d,s,S} C^plan = Σ_{t=1}^{144} p_t E_t（eq:q1-obj，04_q1.tex:35-38）。
- 电量平衡：E_t+(PV_t−L_t)Δt+d_t−c_t−s_t=0，∀t（eq:q1-balance，04_q1.tex:44-48）；功率口径原形 E^buy_t+PV_tΔt+P^d_tΔt+g_t = L_tΔt+P^c_tΔt+s_tΔt（04_验证_陷阱与创新点.md:84）。把「供能 ≥ 负载」写成带弃光松弛的等式是**强化**而非等价（03_数学模型与算法知识点.md:81-83）。
- SOC 递推：S_t = S_{t−1}+η_c c_t − d_t/η_d（eq:q1-soc，04_q1.tex:50-54）；功率口径 S_{t+1}=S_t+η_cP^c_tΔt−P^d_tΔt/η_d，充放比自检 = η_cη_d = 0.81（02_知识点总览_分问清单.md:90, 280）。
- 界与非负：\underline S≤S_t≤\overline S；0≤c_t,d_t≤\overline P Δt；E_t≥0，s_t≥0（eq:q1-socbound/power/nonneg）。
- 日周期：S_0=S_144（题面只要求**相等**）；模板取 =S^init=6000 kWh（eq:q1-periodic，04_q1.tex:69-72；03_数学模型与算法知识点.md:75-79）。
- 命题 1（充放互斥）：η_cη_d<1 时最优解无同时充放。取 δ=min{c_t, d_t/(η_cη_d)}，令 c_t'=c_t−δ、d_t'=d_t−η_cη_dδ ⇒ ΔS = η_c(−δ)−(−η_cη_dδ)/η_d = 0，ΔE_t = −δ(1−η_cη_d) < 0，目标下降 p_tδ(1−η_cη_d)>0，与原最优矛盾（04_q1.tex:100-110）。
- 命题 2（阈值律）：z^c_t = p_t−η_cμ_t ≥ 0 且 c_t z^c_t = 0；z^d_t = −p_t+μ_t/η_d ≥ 0 且 d_t z^d_t = 0（eq:q1-kkt-c/d）；死区 η_cμ_t < p_t < μ_t/η_d ⇒ c_t=d_t=0（eq:q1-deadband）。索引约定：全库统一**同槽 μ_t**，不要再写 μ_{t+1}（03_数学模型与算法知识点.md:101-108）。
- 套利判据：η_cη_d p^high > p^low ⇔ p^high/p^low > 1/(η_cη_d) = 1.2346（单边各 0.9，往返 81%）；若「90%」按往返读则阈值 1/0.9 = 1.111（03_数学模型与算法知识点.md:110-111；README.md:113）。
- 成本分解：Σ_t p_tE_t = C^base + C^batt，其中 C^base = Σ_t p_tΔt max(L_t−PV_t,0)（eq:q1-decomp，04_q1.tex:244-249）；C-01 闭式见 04_q1.tex:213。
- 规模：721 变量（5×144+1，含弃光与 SOC 状态）/ 577（4×144+1）；290 等式（2×144+2）+ 720 界（02_知识点总览_分问清单.md:158；03_数学模型与算法知识点.md:344）。

### 2.3 问题 2：两阶段随机规划 + 报童近似

- 目标：min_{E,c,d,S} Σ_t p_tE_t + Σ_ω w_ω Σ_t 5p_t g_t(ω)（eq:q2-obj，05_q2.tex:79-84）。
- 非预期性：E_t, c_t, d_t, S_t 与 ω 无关（eq:q2-nonanticip，05_q2.tex:86-90）；缺口 g_t(ω) ≥ (L_{ω,t}−PV_{ω,t})Δt + c_t − d_t − E_t，g_t(ω)≥0（eq:q2-gap，05_q2.tex:100-104）。
- 报童：q*_t = F_{D_t}^{-1}( c_u/(c_u+c_o) ) = F_{D_t}^{-1}( 4p_t/(4p_t+c_o) )（eq:q2-newsvendor，05_q2.tex:138-142）；c_u = 5p−p = 4p_t；c_o=p_t → 0.800；实测 p=0.7662、p^min=0.3713 ⇒ c_o≈0.395、c_u=3.065、F*≈0.886（缺货概率 ≈11.4%）（03_数学模型与算法知识点.md:181-182）。
- 惩罚倍数灵敏度：κ=2/3/5/10 → F*=0.50/0.667/0.80/0.90（c_o=p 口径）；c_o≈0.395 口径 → 0.72/0.83/0.886/0.948（03_数学模型与算法知识点.md:187-188）。
- 报童非精确解的四条偏离：多时段耦合；过剩非全浪费；缺口分布不独立；风险度量改变解的形式（05_q2.tex:167-178）。

### 2.4 问题 3：多阶段滚动 / MPC

- 调整费用（模板采用的**偏差量定价口径**）：c_t^buy = p_t min(E^plan_t, E^adj_t) + 0.5p_t (E^plan_t−E^adj_t)^+ + 1.5p_t (E^adj_t−E^plan_t)^+（eq:q3-cost，06_q3.tex:32-38）。
- 线性化：E^adj_t−E^plan_t = u_t−v_t，u_t,v_t≥0；c_t^buy = p_tE^plan_t + 1.5p_t u_t − 0.5p_t v_t（eq:q3-lin，06_q3.tex:49-58）。等价性证明：d_t≥0 时最优 v_t=0；d_t<0 时最优 u_t=0 ⇒ min(u_t,v_t)=0，无需 0-1 变量（06_q3.tex:60-67）。
- 场景树分段：τ(t)=0 当 t∈[1,36]；6 当 t∈[37,72]；12 当 t∈[73,108]；18 当 t∈[109,144]；E^adj_t(ω)=E^adj_t(ω') 对 ω|_{[0,τ(t)]}=ω'|_{[0,τ(t)]}（eq:q3-nonanticip，06_q3.tex:83-99）。
- 目标与缺口：min Σ_t p_tE^plan_t + Σ_ω w_ω Σ_t [1.5p_t u_t(ω) − 0.5p_t v_t(ω) + 5p_t g_t(ω)]（eq:q3-obj）；g_t(ω) ≥ (L_{ω,t}−PV_{ω,t})Δt+c_t−d_t−E^adj_t(ω)（eq:q3-gap，06_q3.tex:115-144）。
- 信息价值：VoI(n) = (C(1)−C(n))/C(1) × 100%（eq:q3-voi，06_q3.tex:167-170）；不等式链 C_PI ≤ C_rolling ≤ C_{n=1} ≤ C_open-loop（eq:q3-ineq，06_q3.tex:209-212）。

### 2.5 问题 4：波动电价与风险

- 两层电价：p_{d,t} = p̄_t + ε_{d,t}，E[ε_{d,t}]=0（eq:q4-price，07_q4.tex:57-61）；残差以「日」为块分块 Bootstrap，电价日块与负载/光伏日块**成对抽取**（07_q4.tex:63-66）。
- 目标：min E[C^total(p(ω),L(ω),PV(ω))] + λ·CVaR_β[C^total(·)]，β=0.95 预先锁定（eq:q4-obj，07_q4.tex:78-85）。
- CVaR 线性化（R–U）：CVaR_α = min_η { η + 1/((1−α)|Ω|) Σ_ω max(0, Cost_ω−η) } → 引入 z_ω ≥ Cost_ω−η、z_ω ≥ 0，仍是 **LP**（03_数学模型与算法知识点.md:331-336）。
- 附录 G.1 拉格朗日与平稳性条件：∂L/∂E_t = p_t+α_t ≥ 0、E_t(p_t+α_t)=0；∂L/∂s_t = −α_t ≥ 0、s_tα_t=0；∂L/∂c_t = −α_t−η_cμ_t+ν^c_t ≥ 0；∂L/∂d_t = α_t+μ_t/η_d+ν^d_t ≥ 0；∂L/∂S_t = μ_t−μ_{t+1}+λ^+_t−λ^−_t = 0（eq:app-stat-*，90_appendix.tex:243-256）；界不活跃连续段上 μ_t=μ_{t+1}，触上界 μ_t<μ_{t+1}，触下界 μ_t>μ_{t+1}（90_appendix.tex:270-274）。
- 附录 G.2 报童 FOC：Π(E)=c_uE[(D−E)^+]+c_oE[(E−D)^+] ⇒ dΠ/dE = −c_u[1−F(E)]+c_oF(E) = 0 ⇒ F(E*) = c_u/(c_u+c_o)（eq:app-nv-foc，90_appendix.tex:282-295）。
