# 08 论文炫技｜结构与叙事：让评审在前三页就相信你

> **审计裁定（14）**：写作骨架全部并入论文，但"证据账本"压缩为**正文证据 ID + 附录表**，不占正文整页；结构图/口径框/假设表/创新五段式/摘要工程为 S 级。

> 数学炫技决定你的**上限**，论文炫技决定你的**实际得分**。
> 一份数学很好但结构混乱的论文，得分会低于一份数学普通但结构清晰的论文——
> 因为评审读的是论文，不是你的代码。
>
> **本文件的定位**：C 题正文 ≤30 页（格式规范第四条），
> **每一页都必须承担一个论证任务**。炫技不是加页数，而是**提高每页的信息密度与说服力**。
>
> 对应总览条目：论文侧的"结构炫技"（`README` 排行榜第 5、6 项）。

## 0. 格式硬约束（先记住，避免低级失分）

| 项 | 要求 | 来源 |
|---|---|---|
| 摘要专用页 | **原则上不超过一页**，含标题与关键词 | 格式规范第三条 |
| 正文 | 从第四页开始，**不要目录，不超过 30 页** | 第四条 |
| 附录 | **页数不限**，必须打印并与正文装订；**应包括支撑材料文件列表与全部完整可运行源码** | 第四条、第五条 |
| 页码 | 从摘要页开始，页脚中部，阿拉伯数字自 1 起连续 | 第三条 |
| 身份信息 | 摘要页、正文、附录**任何地方**都不得出现参赛者、学校、赛区信息 | 第六条 |
| 电子版 | 单独 PDF/Word，**第一页必须是摘要页**（承诺书与编号页不放），≤20 MB | 第十条 |
| 支撑材料 | 全部可运行源码 + 自采数据 + 中间结果图表，压缩为一个 RAR/ZIP，≤20 MB；**文件列表要写进论文附录** | 第十一条 |
| 引用 | 所有引用的他人成果须按科技论文规范列出参考文献并在正文标注 | 第七条 |

> 1. **"缺少必要的源程序、程序不能运行或运行结果与论文不符，都可能会被取消评奖资格"**（第五条）——
>    附录代码必须**真的能跑**，且跑出来与论文数字一致。**提交前必须跑一次附录代码。**
> 2. **支撑材料文件列表必须写进论文附录**（第十一条）——很多人只交了压缩包却没在附录列清单。

## 1. 结构炫技 #1｜决策时序图：一页说清"你在什么时候、知道什么、决定什么"

### 1.1 为什么这张图价值极高

C 题的**全部难点都是信息结构**：四问的差别不是"算法不同"，而是
**决策时刻能获得什么信息、以及决策错了的代价**。
一张时序图能把这个抽象结构**在 30 秒内**讲清楚。

**评审看到这张图，会立刻建立"这队想清楚了"的印象**——而这只需要 1.5 小时。

### 1.2 图的规格（照此画，不要自由发挥）

```
时间轴 ──────────────────────────────────────────────────────────────►

      0:00            6:00           12:00           18:00          24:00
       │               │               │               │              │
信息   ●───────────────●───────────────●───────────────●              │
       │ 附件3预报(24h)│ 附件3预报(24h)│ 附件3预报(24h)│ 附件3预报(24h)│
       │               │               │               │              │
决策   ▼ 计划购电       ▼ 调整购电      ▼ 调整购电      ▼ 调整购电      │
       E^plan_t       E^adj_t(1)     E^adj_t(2)     E^adj_t(3)        │
       │               │               │               │              │
结算   ────────────────┴───────────────┴───────────────┴──────────────┤
       以附件2「实际」负载与光伏结算；缺口按 5 倍电价紧急购电
       少买部分违约 0.5p；多买部分 1.5p
```

**关键标注（多数人会漏）**：
1. **"计划依据"与"结算依据"是两套数据**——在图上用不同线型区分；
2. **18:00 的预报覆盖到次日 18:00**——用一条跨越 24:00 的箭头表示（这是问题 3 最易错处）；
3. **紧急购电发生在实时（结算时）**，不在决策时刻；
4. 四问在图上的差别：问题 1 只有 0:00 一个决策点且无惩罚；问题 2 有 0:00 + 实时惩罚；
   问题 3 有 4 个决策点；问题 4 在图旁标注"电价亦为随机"。

> **一句话模板（写在图下方）**：
> "四问的差别不在于模型复杂度，而在于**信息结构**：
> 决策时刻从 1 个增加到 4 个，计划依据从确定值变为预报值，
> 且引入了违约（0.5 倍）与紧急购电（5 倍）两类不对称惩罚。
> 本文的模型围绕这一递进结构展开。"

### 2.1 图的内容

```
                                       ▼
   附件4 波动电价 ──────►┌─────────────────────────────────────┐
                        │ Q4  波动电价（重算 Q2 与 Q3）           │
                        │ 产出：result4-2 / result4-3、风险前沿    │
                        └─────────────────────────────────────┘
```

### 2.2 依赖表（与图配套，必须说明"误差如何传播"）

| 上游 → 下游 | 传递的内容 | 潜在的误差传播 | 本文的处理 |
|---|---|---|---|
| Q1 → Q2 | 模型骨架、水价值语言、$C^{base}$ 定义 | 附件 1 是**全年逐时段均值**（= 全年均值日），结果窗口是 2025-02-01…12-31，两者不是同一批数据：逐时段均值差为 **电价 0.0306 元/kWh、负载 48.14 kW、光伏 150.03 kW**，直接套用会把基线与节省率算偏 | 显式声明两套口径：Q1 报**典型日**结果、窗口基线 $C^{base}$ **按窗口重算** |
| Q2 → Q3 | 场景生成方法、安全边际 $\alpha^\ast$ | 场景分布偏离真实分布 | Q3 用同一场景集，保证可比 |
| Q3 → Q4 | 滚动框架、终端水价值 | 电价随机性叠加预报误差 | 联合情景（Copula / 分块 Bootstrap） |
| Q1 → Q4 | 阈值律 | 阈值取值依赖价格分布 | 说明**形式不变、取值改变** |
| 全部 | $C^{base}$ 基线 | 基线口径不一致会使"节省率"不可比 | **四问统一用同一基线定义** |

> **这一节的价值**：它把"四问"变成"一个逐步放宽信息假设的模型族"，
> 而**这正是命题人设计这道题的意图**。写出这一层，说明你理解了出题逻辑。

## 3. 结构炫技 #3｜口径框：消灭"这个数是怎么算的"这类质疑

### 3.1 问题

论文中最常见的失分点不是算错，而是**口径不清**：
"节省 26.9%"是相对谁？"全天购电量"含不含储能充电？"购电费"含不含紧急购电？

### 3.2 做法：为每个关键指标配一个**口径框**

```
┌─ 口径 C-01：无储能基线购电费 ────────────────────────────────┐
│ 定义  C^base = Σ_t p_t · Δt · max(L_t − PV_t, 0)              │
│ 数据  L, PV 取附件 2 当日实际值；p 取附件 4（波动价口径）        │
│ 时段  t = 1..144，Δt = 1/6 h；窗口：2025-02-01 … 2025-12-31   │
│ 单位  元（保留 2 位小数）                                      │
│ 不含  储能充电成本、紧急购电、调整/违约费用                      │
│ 对照  固定价口径（附件 1）下同一量 = {…} 元，差异 {…}%          │
│ 复算  `C题炫技方向/13` §3 `baselines(L,PV,P)`（C-01 三变体） │
└──────────────────────────────────────────────────────────────┘
```

**放在哪里**：第一次出现该指标的小节，或集中放在"符号说明"之后的一页"指标口径表"。

> **为什么这是"炫技"**：
> ① 它让评审**不用猜**；② 它让你的结果**可被复算**；
> ③ 它把"口径不一致"这类质疑**提前消灭**。
> **成本：1 小时。收益：消除一整类失分。**

### 3.3 必须配口径框的核心指标（至少这 8 个）

| # | 指标 | 最易出现的口径歧义 |
|---|---|---|
| 1 | 全天购电量 | 是否含储能充电量？是否含紧急购电？ |
| 2 | 全天购电费 | 是否含紧急、调整、违约？ |
| 3 | 节省率 | 相对哪个基线？（无储能？贪心？完美信息？） |
| 4 | 紧急购电量 | 是否含调整机制引入的缺口？ |
| 5 | 弃光电量 | 是否非负？是否按电量（kWh）而非功率？ |
| 6 | 充/放电量 | 是交流侧（AC）还是直流侧（电池侧）？**效率算在哪一侧？** |
| 7 | 储电量 SOC | 时段初还是时段末？0:00/24:00 是否相等？ |
| 8 | 预报误差 | 全样本还是白天？MAE 的分母是什么？ |

> ⚠️ **第 6 项特别致命**：充放电效率 90% 可以记在充电侧、放电侧或两侧，
> **三种口径下 Q1 的节省额相差 13.2%**：两侧各 0.9 → **12 925.10 元**；
> 仅放电侧 0.9 → **13 883.44 元**；仅充电侧 0.9 → **14 635.52 元**
> （套利阈值 **1.2346**；若按"往返效率 90%"的读法则阈值是 1.111，**必须注明是哪一种口径**）。
> 必须显式声明，并做灵敏度（`C题知识点解析/01` 假设 A2）。

## 4. 结构炫技 #4｜"证据账本"主表：每个结论都能被追溯

### 4.1 这是什么

正文只保留**证据 ID**（放在"问题分析"之后或关键结论处），**完整表放附录**——不要把整张表塞进正文（审计 `14`：它会占掉近一页，挤压主干结果）。
把**全文所有关键主张**与**支撑它的证据**一一对应。

| 主张 ID | 问题 | 主张（可证伪的陈述） | 证据类型 | 图/表/式 | 适用范围 | 反例/风险 |
|---|---|---|---|---|---|---|
| C-Q1-01 | Q1 | 典型日最优弃光为 0 | 数值解 + 约束紧性分析 | 表 x / §x | 全年平均日 | 问题 2–4 的**实际日序列**有 72/334 天弃光 >0（见 C-Q4-01） |
| C-Q1-02 | Q1 | 最优策略为互补松弛型阈值（满充/满放/由界决定） | 对偶推导 + KKT 四条条件满足率 100% + 恒等式偏差 ≤2.2e−16（**纯套利子问题**；完整 P1 在边界活跃时段回退到互补松弛的 $z$ 形式） | 式 (11) / 图 x | 纯套利子问题（变量仅 $c,d,S$）；界不活跃时段可用 (11b) | 完整 P1 中 29/145 个 SOC 落在边界，该恒等式在大量时段不成立 |
| C-Q1-03 | Q1 | 储能节省 {x}%（相对无储能基线） | LP 最优 vs 闭式基线 | 表 x | 全年平均日、固定价 | 口径差异见 C-01 |
| C-Q2-01 | Q2 | 计划覆盖率的经验值落在报童两界之间 | 数值解 vs 式 (17) 两种 $c_o$ 口径 | 图 x（散点） | 光伏误差为主要不确定性 | 负载误差未建模 |
| C-Q3-01 | Q3 | 增加预报时刻的边际收益在 n=4 附近饱和 | 五组 $n$ 对照实验 | 图 x | 本题误差与惩罚结构 | 若惩罚倍数改变，需重算 |
| C-Q4-01 | Q4 | 互补松弛型阈值刻画在波动电价下形式不变 | 对偶推导（分布无关）+ KKT 数值验证 | 式 (11) | 线性目标 + 储能递推结构 | 界活跃时需回到 $z$ 形式 |

### 4.2 三条使用规则

1. **正文每个关键结论都要有 ID**，且在文中以"（见 C-Q3-01）"标注；
2. **"反例/风险"列必须有内容**——写"无"会被认为没想过边界；
3. **证据类型要具体**：写"数值实验（n=5 组对照）"，不要写"分析"。

> **为什么这是最高性价比的写作炫技**：
> 它强制你**删除所有无证据的结论**。
> 一份"每个断言都可追溯"的论文，与一份"夹着一堆'效果良好'"的论文，
> 在评审眼里的可信度是两个档次。
> **成本：1 小时（但如果你的结论经不起追溯，它会暴露问题——这正是它的价值）。**

## 5. 结构炫技 #5｜模型假设表：每条假设都有"为什么"和"会怎样"

### 5.1 反例（常见写法）

> "为简化问题，本文作如下假设：① 忽略电池自放电；② 假设电价已知；③ 假设……"

**问题**：没说"不用这条假设会怎样"，也没说"怎么验证"。
这类假设是**装饰性**的，评审会认为你只是凑格式。

### 5.2 正确模板

| 编号 | 假设 | 必要性（不用会怎样） | 现实/题目依据 | 影响方向 | 验证或灵敏度方式 |
|---|---|---|---|---|---|
| A1 | 不允许向电网售电 | 否则目标少一项、盈余有出路，弃光恒为 0 | 题面未给上网电价 | 使费用**偏高** | 引入上网电价 $\theta$ 扫描（见 §x） |
| A2 | 充/放电效率各 0.9（往返 0.81） | 决定套利是否有利 | 题面"效率 90%"，未区分方向 | 效率↓ → 套利收益↓ | 0.85/0.90/0.95 三档 + 单侧口径对照 |
| A3 | 不同时充放电 | 若允许需 0-1 变量，规模翻倍 | 效率 <1 时严格劣（已证） | 不影响最优值 | 数值解断言 $\min(c_t,d_t)=0$ |
| A4 | 无自放电与循环衰减 | 否则需循环成本项 | 题面未给 | 高估长期收益 | 加循环成本 $c_{cyc}$ 灵敏度 |
| A5 | 跨日 SOC 连续递推 | 否则每日清零，与初值 6 000 kWh 矛盾 | 附录初值 + 运营常识 | 影响全窗费用 | 与"逐日独立"对照 |
| A6 | 结果窗口末日 $S_T\ge\underline S$ | 防"末日掏空"短视解 | 运营常识 | 影响末期费用 | 终端处理四组对照 |

### 5.3 两条删除规则

| 该删的 | 原因 |
|---|---|
| 建议保留一位小数/数据已清洗等 | 属于数据处理，不是模型假设 |
| 未被任何公式使用的假设 | 装饰性，删掉反而更专业 |

> **判据**：一条假设若不能回答"**不用它模型会怎样**"，它就不该出现在假设表里。

## 6. 结构炫技 #6｜创新五段式：把"我用了 X 方法"变成"我解决了 Y 缺陷"

### 6.1 五段式模板（每个创新点都照此写）

```markdown
### 创新 {n}：{一句话名称}

**缺陷**  基线方案在 {某个假设/环节} 上存在问题：{具体表现为…}。
          {用残差/题意/数据证据/约束分析} 可以观察到 {现象}。

**改动**  本文引入 {具体改动}，其数学作用是 {写成公式或约束}（式 {编号}）。
          与基线的差别在于 {一句话}。

**证据**  在 {同一场景集 / 同一实际轨迹 / 同一预算} 下，
          相对基线 {指标} 由 {a} 变为 {b}（改善 {x}%）。
          消融实验显示：移除该改动后，{指标} 回落到 {c}（见 表 {编号}）。

**代价**  {计算量 / 数据需求 / 解释成本} 增加 {具体量}。
          {若代价超过收益，则说明本文在何种条件下退回基线}。

**边界**  当 {条件} 成立时，该改动不再适用（例如 {情形}），此时应退回 {方案}。
```

### 6.2 一个完整的示例（可直接改写）

```markdown
### 创新 2：面向价格而非面向负载的储放电策略

**缺陷**  常规做法按"负载高峰放电、低谷充电"设计策略。
          但本文的数据核查发现，负载峰（09:00）与电价峰（19:00）
          平均相差 8.35 小时，仅 41.1% 的日子负载峰落在"当日高价时段"（见 §x）。
          **口径必须写明**：负载峰与电价峰均按**逐时均值的 argmax** 判定
          （若改用原始 10 min 数据取 argmax，会得到不同结论）；
          这里的"当日最高价时段"实为**当日前 4 高的小时**，
          若按字面"当日最高的那一个小时"严格计数，命中率仅 1.6%。
          因此面向负载的策略会系统性错过高价窗口。

**改动**  本文以 LP 对偶量 ρ_t（储电边际价值，即"水价值"）为核心，
          将对偶最优性条件整理为互补松弛型阈值刻画（式 (11)）：
          p_t < η_c·ρ_{t+1} 时充电、p_t > ρ_{t+1}/η_d 时放电。
          该策略的决策依据是价格与水价值的比较，而非负载水平。

**证据**  在全年平均日上，阈值律解与数值最优解一致
          （费用相对偏差 ≤ 1e-4，阈值律一致性检验违反 0 次）；
          相对"面向负载"的贪心策略（基线 B2），费用由 {a} 元降至 {b} 元（降低 {x}%）。
          KKT 四条互补松弛条件满足率 100%、恒等式 z^c_t=p_t−η_c·μ_t、z^d_t=−p_t+μ_t/η_d
          的偏差不超过 2.2e−16（**该 KKT 证据只在纯套利子问题上成立**
          ——即变量仅 c,d,S，完整 P1 在边界活跃时段回退到互补松弛的 z 形式；
          完整 P1 中 145 个时段有 29 个 SOC 落在边界，该式在大量时段不成立），
          阈值四边极值均 ≈0（恰好相接、无缝隙无重叠）。

**代价**  需要求解 LP 以获得对偶量（相较贪心策略增加约 {t} 秒计算量），
          并将其纳入模型。

**边界**  当电池触及容量界或充放功率界时，界乘子活跃，
          电价与水价值的简单阈值不等式不再成立（此时由界乘子补偿），
          须回退到互补松弛的 z 形式 (11)。
          完整 P1 尤其如此：E_t 无上界、B_t=0 绑定会造成对偶退化，
          145 个时段中 29 个 SOC 落在边界，故本文只在**纯套利子问题**上陈述该恒等式。
          当电价无峰谷结构（价差低于 1/(η_cη_d)≈1.2346）时，
          最优策略退化为"不充不放"，阈值律自然给出该结论，
          此时储能不再有套利价值，建议不投建储能。
```

> **这个模板的杀伤力**在于：它让"创新"变成**可验证的命题**，而不是形容词。
> 而且"边界"一段会自动逼出"什么时候该放弃这个创新"——
> **能说出自己的方法何时失效，是最高级的自信。**

### 7.2 五条摘要铁律

| # | 铁律 | 违反后果 |
|---|---|---|
| 1 | **每个数字都必须是你真算出来的**，未算出时写 `{待计算}` | 编造数字 = 学术不端 |
| 2 | **必须有量化结果**，不能只写"建立了模型并求解" | 评审认为你没做出来 |
| 3 | **必须有一句"为什么这样建模"**（结构匹配理由） | 显得是套模板 |
| 4 | **必须有验证的一句话** | 可信度不足 |
| 5 | **必须有一句适用边界** | 过度声称 |
| 6 | 篇幅**控制在一页内**（格式规范第三条） | 违规 |

> **写作顺序建议**：**最后写摘要**，但**先写摘要的骨架**。
> 建模开始时就把上面模板抄下来、留好占位符，
> 每算出一个数就填进去——**这样摘要永远不会和正文不一致**。

## 8. 章节设计：每章回答一个评审问题

> **骨架口径（与 `C题写作需求/论文写作需求操作文档.md` §3.0 一致）：按"问题"分章，不按"建模—求解—检验"分章。**
> 全文没有独立的"模型建立 / 模型求解 / 模型检验"大章，这三个动作下沉到**每个问题章内部**（x.1 / x.2 / x.3）。
> 版面因此与评分点一一对应：阅卷人跳读、分问打分，每问自成闭环最省他找分的时间。

```text
摘要 + 关键词（按问题分段）
第 1 章 问题重述         ┐
第 2 章 问题分析         │ 准备层（5 章）：一次铺完底座
第 3 章 数据预处理与特征分析 │ （本题数据必须单独立章，理由见写作需求 §3.0）
第 4 章 模型假设         │
第 5 章 符号说明         ┘
第 6~9 章 问题一~四：每章固定 x.1 模型建立 / x.2 求解与结果 / x.3 检验与灵敏度
第 10 章 模型评价与推广 + 参考文献 + 附录 A/B/C（+ 扩展）
```

| 章节 | 评审在问什么 | 本节必须出现的东西 |
|---|---|---|
| **1 问题重述** | "你知道题目在问什么吗？" | 1.1 背景 3–5 句；1.2 **编号 4 条**（与第 6–9 章一一对应）；1.3 交付物表（5 个结果文件 ↔ 题面表 1/2/3/4） |
| **2 问题分析** | "你想清楚了吗？" | 2.1 **子问题结构诊断表**（每问一行：信息结构 / 数学特征 / 决定性建模要素 / 主结果）；2.2 关键矛盾与突破口；2.3 **决策时序图 + 问题依赖图 + 误差传播表**，并写出"一个模型族、两个开关" |
| **3 数据预处理与特征分析** | "数据你读懂了吗？" | 3.1 时标与口径对齐（标签=时段末端、10 min 槽 ↔ 整点、**附件 1 身份核查 = 全年逐时段均值、非预报**）；3.2 相关性的尺度拆解（全年/季节/日内三档，带样本量）与负荷—光伏形态；3.3 预报误差分档（全样本/白天双口径）；3.4 长明细表移附录 B、正文只留被引用的结论 |

| **5 符号说明** | "符号清楚吗？" | **一张表：符号 / 含义 / 单位**，覆盖四问（含对偶变量、情景下标），另注明上下标约定 |
| **6 问题一：典型日确定性计划** | "确定性版本做对了吗？" | **6.1** 变量→目标→约束逐条编号 + 模型类型判断（LP）+ 对偶水价值与阈值律 + $C^{base}$ 闭式；**6.2** 求解器 1 段 + 总结果表 + 表 1/表 2 格式明细 + 1 图；**6.3** ①恒等式/SOC 残差表 ②基线（无储能，节省 26.90%）③灵敏度（$\eta$/终端/双向扫描）+ 稳健性小结 |
| **7 问题二：不确定性与日前计划** | "不确定性处理合理吗？" | **7.1** 信息结构 + 两阶段随机规划 + 场景生成三层保真 + 报童临界分位数及四条边界；**7.2** 四项费用分解总结果表 + **表 3 四日期（2025.3.20/6.21/9.23/12.21）明细** + 1 图；**7.3** ①供给缺口残差 ②基线（安全边际 3 133 767.55 元）③灵敏度（$\kappa$、SOC 区间）+ 小结 |
| **8 问题三：多时刻预报与调整** | "多阶段做对了吗？" | **8.1** 决策结构 + 分段线性凸成本 + **非预期性约束** +（三级标题）"预报需求分析"；**8.2** MPC 伪代码 1 段 + 总结果表 + 四日期明细 + 1 图；**8.3** ①滚动一致性/非预期性校验 ②基线（VoI 2.33%，已实现 85.1%）③灵敏度（信息层数、预报误差）+ 小结 |

| **10 模型评价与推广** | "你诚实吗？能推广吗？" | 10.1 优点 4–6 条（带"人无我有"：统一性 / 可证最优 / 显式处理退化性）；10.2 缺点与改进（**每条缺点紧跟一条改进**，含影响方向 + 验证路径）；10.3 推广 2–4 个场景（"改哪个参数 / 加哪个约束即可"） |
| **参考文献** | "引用规范吗？" | 7–10 条：教材 + 领域综述 + 算法原始文献 + 竞赛规范；正文标注 ↔ 文献表双向一致 |
| **附录 A/B/C（+ D/E）** | "能复现吗？" | **A 程序清单**（文件→职责，含环境/种子/运行说明）、**B 结果文件说明**（文件名→内容 + 数据字典 + 逐日明细）、**C 关键推导**（对偶、报童、能量恒等式）；**D 独立审计与验证链**、**E 口径定义汇总**（本题加分项，排在 A/B/C 之后）；§12.1 必备八项一项不漏 |

> **每问章内的三段式是硬约束**：`x.1 模型建立`（变量 → 目标 → 约束逐条编号 → 模型类型判断）、
> `x.2 模型求解与结果分析`（求解器 1 段 → 总结果表 → 代表日明细表 → 1 张图）、
> `x.3 检验与灵敏度分析`（**①内部一致性/恒等式残差表 ②基线对比给下降百分比 ③关键参数灵敏度表** → 稳健性小结）。
> 三级标题四问**同名同序**：`x.3.1 内部一致性与基线对比`、`x.3.2 <关键参数>的灵敏度分析`、`x.3.3 稳健性小结`。

> **后几问可以写短，但不能只写"同问题一"**：写成"**仅修改 X 与 Y，其余同式 (x.n)；差异点有三：…**"。
> 模板原型（同类获奖论文 26 页）问题层四问配比约 4:4:4:2——**递减的是篇幅，不是论证动作**。

> **"模型评价"节的写法要点**：
> 局限不能写"数据有限"这类空话，要写
> **"哪条假设可能偏离现实 → 偏离会让结论往哪个方向变 → 什么数据能验证 → 部署前如何校准"**。
> 四要素齐全才叫局限，否则叫推脱。
