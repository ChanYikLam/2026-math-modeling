# C 题《微网与外部电网电力调控策略》——论文与复现工程

> 本文件夹是 **2026 高教社杯全国大学生数学建模竞赛 C 题**的**独立完整交付**：
> 一套可编译的论文（LaTeX）、一套可从原始附件重算出论文每一个数字的源程序、
> 五个结果文件、全部矢量图与独立审计报告。
>
> 与仓库中 `论文/`（写作模板）的区别：`论文/` 是空骨架（417 处占位符），
> 本文件夹是**已完成的论文**——所有数字都由 `code/` 下的程序从 `附件 1–4` 重新算出，
> 论文正文与结果文件逐格一致。

## 二、三分钟复现

```bash
cd code
python3 -m pip install -r requirements.txt     # numpy/pandas/scipy/openpyxl/matplotlib/scikit-learn
python3 run_all.py                             # 约 22 分钟，生成全部结果文件、中间结果与 15 张矢量图
python3 run_all.py --fast                      # 约 4.4 分钟，仅主链 + 审计 + 台账（跳过对照实验与图件）
python3 audit.py                               # 独立审计 AU1–AU10（从结果文件复算）
python3 paper_numbers.py                       # 汇总论文数值台账
```

脚本也可从任意工作目录单独运行（`python3 code/exp/exp_dro.py`、`python3 code/q2/q2.py --help`），
目录引导集中在唯一的 `code/_pathsetup.py`，脚本之间仍是扁平导入（`import config as C`）。

编译论文（需要 XeLaTeX 或 tectonic）：

```bash
./build.sh                 # 自动探测 latexmk+xelatex / xelatex / tectonic，产出 main.pdf
touch final.flag && ./build.sh && python3 tools/check_paper.py --strict   # 定稿模式 + 合规自查
```

- **信息价值**：4 次预报相对 1 次节省 332 389.18 元（2.33%），已实现完全信息上界价值的 85.1%，再加密最多再省 0.42% → 不建议继续加密；
- **瓶颈**：容量摆幅是主要瓶颈（解除容量上限可再省 22.1%），充放电功率在部分时段同时构成约束（解除后仅再省 1.7%）；
- **套利条件**：峰谷价比高于 1/(\eta_c\eta_d)=1.2346 时有利。

### v2 新增的对照实验（"结论是否成立"的证据，而不是更多模型）

| 对照 | 关键数字 | 结论 |
|---|---|---|
| C 藤 pair-Copula 相依结构（S3.6） | tau(电价,负载)=+0.698；电价—光伏由自由度 3.23 的 t Copula 给出 tau=-0.238、lambda_U=lambda_L=0.0479 | 尾部共现存在但弱；决策相关的"电价—预报残差"对近似独立（tau=-0.0259） |

| 机会约束对照（S5.6） | 最优档 beta=0.10 总费用 14 339 249.60 元，仍比随机规划贵 0.52% | 期望值随机规划优于逐槽分位数边际；实测缺电频率约为标称 beta 之半 |
| 盒式分布鲁棒对照（S7.5） | 最优 k*=1.5 回测 16 819 102.59 元，比随机规划高 11.43%、CVaR 高 8.72% | 全盒鲁棒被全面占优，只能作最坏情形上界 |

| L 形（Benders）分解对拍（S9.7） | 334 天两算法最大相对间隙 3.76e-15；K=500 单日 2.38 s -> 0.18 s（13.2 倍） | 主结果另有独立数值路径复核 |

### 本轮修订的机制性改动（防止同类问题复发）

| # | 改动 | 原因 |
|---|---|---|
| 1 | `\appref{label}{附录定位}` 宏（`preamble.tex`）**只输出手写定位**「附录 K.3 …」，三个交付形态一致；新增 `check_paper.py` 的「附录定位核对」逐条比对实际附录字母 | 旧实现按是否载入附录切换 `\ref`/备用文字，导致 main.pdf 与 full.pdf 出现两套不同编号，且正文引用的 E/F/H/I/J 与实际附录 A--S 不符（"跳号附录"缺陷） |
| 2 | 交付形态拆为三册：`main.tex`（正文）、新增 `appendix.tex`（附录）、`full.tex`（合并版）；`build.sh` 一个命令编全部三册 | 正文单独一册、附录单独一册；`build.sh` 内已固定 main → appendix → full 的顺序 |
| 2b | 新增 `\bref` 宏：附录回指正文时输出"正文表 20 / 正文式 (2a) / 正文第 3.7 节" | 附录单独成册时正文编号不在本文件内；`appendix.tex` 用 `xr` 读 `build/main.aux` 取真实编号，39 处引用全部可解析 |
| 3 | 新增 `\chapref{label}` 宏，正文 25 处硬编码「第X章」全部改为 `\chapref` | 硬编码章号在增删章节后必然失配 |
| 4 | 符号说明表从附附录 H 移回正文 §2.3 | 写作需求要求"完整符号表含单位"且"公式中每个符号都必须在符号表中出现"；此前公式里的对偶变量在正文无定义 |
| 6 | 正文大幅精简 + 数学化改写：正文 27 → 23 页（**本轮评审修复后为 27 页，仍在 30 页上限内**）；散文句中位数 113 → **39 字**、>150 字长句 22 → **0 句**；逐问给出编号式（式 (1)--(40)）替代文字描述 | 原稿每句平均承载 2--3 个独立事实、绝对谓语密集；现改为"一句一个判断 + 公式承载关系" |
