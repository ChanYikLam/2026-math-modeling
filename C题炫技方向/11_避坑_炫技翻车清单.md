# 11 避坑｜炫技翻车清单：50 条会把加分变成减分的做法

> **审计裁定（14）**：本文件是执行层清单，**不并入论文正文**；其中 A 组红线优先级高于任何炫技。

> 炫技的失败模式**不是"不够花哨"，而是"花哨但空"或"花哨但错"**。
> 这份清单按**翻车概率 × 后果严重度**排序，最后附**评审视角的三类判决**与**被质疑时的应答脚本**。
>
> ⚠️ **本清单中带 🔴 的条目，是本次数据复算中真实出现过或极易出现的问题**，
> 而不是泛泛而谈的"注意事项"。

## B. 二级翻车（评审会直接判定"方法选择错误"）

| # | 翻车做法 | 为什么错 | 正确做法 |
|---|---|---|---|
| B1 | **LP 问题用遗传/粒子群/模拟退火作为主求解器** | 本题可精确全局最优；启发式慢、无最优性保证、**且丢掉了对偶信息**（那是本题最大的红利） | 精确求解；启发式仅作对照，且必须给 gap 与基线（`07` §1） |
| B2 | **硬塞 AHP / 熵权 / CRITIC / TOPSIS 组合** | 本题是纯优化，无多指标评价任务 | 若要做决策建议，用**多目标 Pareto 前沿**（`05` §6） |
| B3 | **声称"引入深度学习做光伏预测"** | 附件 3 已给预报；题目不问预测；365 天样本不足；引入无法解释的黑箱 | 只做**预报误差的统计刻画**（分布、相关、校准），服务于优化 |
| B4 | **套用"数字孪生 / 碳交易 / 元宇宙 / 区块链"等无关名词** | 与题目无关，典型减分 | 删掉 |
| B5 | **报童模型直接当精确解** | 本题多时段 + 储能跨期耦合，纯报童只在"单时段、无储能、过剩全浪费"时严格成立 | 用作**近似刻画 + 上下界 + 直觉解释**，并写明 4 条偏离来源（`03` §1.4） |
| B6 | **CVaR / 鲁棒 / 随机规划三个模型并列但不做对照** | 三个数说不清差异来源，属"并列堆砌" | 固定同一场景集与同一实际轨迹，报告**相对差值**与各自适用偏好（`03` §4–5） |
| B7 | **多智能体 / 博弈论**（除非明确标为推广） | 题目设定微网是价格接受者、单一决策者 | 若想讲市场，做"若微网有定价权"的**推广情景**并明确标注 |
| B8 | **引入需求响应模型** | 🔴 **本题数据中没有可识别的价格弹性证据**：电价残差与超前/滞后负载残差的互相关在 lag −6…+24 槽**全部为正**（+0.49…+0.69），无"高价后负载下降"特征 | 用数据**明确拒绝**该扩展（`06` §5.3c）——这比强行加模块更专业 |

## C. 三级翻车（建模与数值错误）

| # | 翻车做法 | 后果 | 正确做法 |
|---|---|---|---|
| C1 | **kW / kWh 混用**（忘乘 $\Delta t=\frac16$ h） | 🔴 结果整体差 6 倍 | 统一"电量变量 = 功率 × Δt"，符号表标注单位 |
| C1b | 🔴 **把流量平衡等式代入目标后再交给求解器** | 🔴 **求解器不报错**，只给一个"看起来合理"的错误答案（本次实现中真实踩到：费用算成 5854 元而非 35 127 元）。成因是：平衡等式被代入目标后，求解器返回的"目标值"被该等式的**行对偶整体平移了 $\sum_t\lambda_t$**——**与功率界是否乘 $\Delta t$ 无关**。比 C1 更危险，因为没有任何报错信号 | **不要把等式约束消元进目标**；诊断法：用 `(p_t*(B_t+S_t)).sum()` 或独立复算目标，与求解器返回值比对——**若差一个常数，检查是否有等式约束被代入目标**。同时仍要**锁定一种口径并全局贯彻**：① 若变量为**电量 kWh**，则目标系数是 $p_t$、功率界是 $\overline P\Delta t=833.33$ kWh；② 若变量为**功率 kW**，则目标系数是 $p_t\Delta t$、功率界是 $\overline P$。**写进代码注释与符号表** |
| C1c | 🔴 **充放电效率的方向写反**：把 SOC 递推写成 $S_t=S_{t-1}+\eta_cc_t-\eta_dd_t$ | 🔴 充放比变成 $\eta_d$ 而非 $\eta_c\eta_d$（实测 0.9 vs 正确 0.81），套利收益与容量核算全部失真；**且 LP 仍然求解成功** | 正确形式：$S_t=S_{t-1}+\eta_c c_t-\dfrac{d_t}{\eta_d}$（**充电乘效率、放电除效率**，放电效率在**分母**）。用"充放比 = $\eta_c\eta_d$"或"$E_{dis}/E_{ch}=0.81$"作为断言自检 |
| C1d | 🔴 **对偶变量符号/相位靠猜**：写阈值律时不确定该用 $\mu_t$ 还是 $\mu_{t+1}$、是否取负、效率是乘还是除 | 🔴 公式"看起来对"但与数值解不符，评审一验即穿 | **不要猜**：① 用最小算例标定符号（如 $\min\sum pE$ s.t. $E\ge N\Delta t$，其对偶恰为 $p$）；② 用 KKT 界乘子恒等式反推（$z^c_t=p_t-\eta_c\mu_t$、$z^d_t=-p_t+\mu_t/\eta_d$，应精确成立到 $10^{-16}$）；③ 断言"可改进方向数 = 0"。详见 `02` §3.5 |
| C2 | **丢掉最后一列 `0:00+1`** | 🔴 每一处能量与费用合计**偏低 0.6944%**（1/144） | 明确：标签 = 时段**末端**；144 个值对应 144 个 10 min 区间，无缝铺满 [0:00, 24:00)。注意 `result1` 与 `result2/3/4-*` 的末标签**写法不同**（`result1` 为 `0:00+1-0:10+1` 且无全天行；`result2/3/4-*` 为 `0:00-0:10+1`），见裁定基准 `D12` |
| C3 | **附件 3 提前期错位**（误用 $[h_0+k,h_0+k+1)$） | 🔴 全部预报整体错 1 小时；白天 MAE 由 **694.74** 恶化到 **872.32** kW | 用 $[h_0+k-1,h_0+k)$，并数值校验（实测：$k$ 映射的白天 MAE 为 872.32、$k-1$ 为 694.74，即 **$k$ 比 $k-1$ 差 26%**；$k+1$ 的全样本 MAE 为 931.91，即 **比 $k-1$ 差 2.63 倍**） |
| C4 | **附件 3 日期列稀疏未 ffill** | 🔴 3/4 的预报行没有日期，对齐失败 | 读入后立即 `ffill`，并断言每天 4 行 |
| C5 | **18:00 预报的跨日处理错误** | 🔴 18:00 的 k=7…24 落在**次日** 0:00–17:00（18 个值）；若留在当日行，问题 3 系统性失真 | 用绝对时间轴映射：目标小时 = 发布日×24 + h₀ + k − 1；越界配对丢弃并说明丢弃数（36/35040 = 0.10%） |
| C6 | **逐日独立求解，每天把电池清零/掏空** | 🔴 与附录"1 月 1 日 0:00 为 6 000 kWh"矛盾，且抹掉跨日套利 | 按题面**每天 0:00 重新制定当天计划**，并**显式声明日末 SOC 的处理**（延续 / 重置 6 000 / 日环状），三选一做灵敏度；同时声明 **2025-02-01 初始 SOC 的来源**（裁定基准 `D13`）；结果表逐日给出 0:00/24:00 储电量 |
| C7 | **终端无约束**，出现"最后一天把电卖完" | 🔴 短视解，末期费用异常低 | 终端水价值 / 硬边界 / 延长窗口三选一，并量化短视代价（`04` §4） |
| C8 | **把"最优弃光"误写成"结构性必需的结果"** | 🔴 已复算：全年平均日的日内盈余总量仅约 6 248 kWh、峰值盈余功率仅约 2 118 kW，**均低于储能可用摆幅 9 600 kWh 与充电上限 5 000 kW，故最优弃光 = 0，弃光约束非紧**。写成"必须弃光"会被判为没有实际求解 | 正确表述："弃光**变量**是必需的（保证极端日可行），但平均日的**最优弃光为 0**"；**实际日序列 72/334 天**弃光 > 0（附件 2 全年有 241 个时段的盈余功率 > 5 000 kW）（`02` §6.0） |
| C9 | **效率口径含糊**（只写"效率 90%"不说是充电侧还是放电侧） | 🔴 三种口径的 Q1 最优节省为 **12 925.10（两侧 0.9）/ 13 883.44（仅放电侧 0.9）/ 14 635.52（仅充电侧 0.9）元，极差 13.2 %**（旧稿"约 10 %"作废） | 显式声明并做灵敏度（假设 A2）；阈值 1.2346（"往返 90 %"读法为 1.111） |
| C10 | **用"峰谷价比 2.98"论证套利空间** | 🔴 方向对但论证不严谨：2.98 是"夜间谷 vs 傍晚峰"，而储能实际搬运的是**午间盈余**（盈余加权均价 **0.5536 元/kWh（结果窗口）/ 0.5555 元/kWh（全年）**） | 用真实通道论证：盈余均价 0.5536 → 峰段 1.27，**电价比倍数 ≈2.3**；若按**含效率口径**（搬运 1 kWh 需充 $1/\eta_c$）则为 ≈2.07。**同一篇论文只能用一种口径**（两者均高于阈值 1.235）（`06` §5.3） |
| C10b | 🔴 **把阈值律写成"存在全天统一的电价阈值 $p^\ast$，低于它就充电"** | 🔴 与数据不符：水价值 $\mu_t$ 实测有**多个不同取值（完整 P1 实测 77 个，因 $B_t=0$ 绑定导致对偶退化）**、范围约 **[0.47, 1.29]**，因此阈值 $\eta_c\mu_t$ 是**时变**的（实测 $\eta_c\mu_t\in[0.43,1.16]$）；**"阈值时变、不存在全天统一阈值"这一结论不变**。写成统一阈值会被内行一眼看出是未经检验的简化 | 正确表述："最优策略为**两级结构**：先由 LP 对偶定出水价值曲线 $\mu_t$，再逐时段比较 $p_t$ 与 $\eta_c\mu_t$、$\mu_t/\eta_d$。" 并明确写出**该刻画在界活跃时需回到互补松弛形式**（`02` §3.1c、§3.3） |
| C10c | 🔴 **把完整 P1 与纯套利子问题的对偶混为一谈** | 🔴 完整 P1 中 $E_t$ **没有上界**，其对偶结构与纯套利问题不同（实测：纯套利子问题的四条阈值条件满足率 100%；完整 P1 中因 $B_t=0$ 绑定，**充电侧有 44/144 个时段**无法用阈值式判定，放电侧 0 违反）。直接照搬会得出错误结论 | 先做 §2 的分解，**在纯套利子问题上陈述并验证阈值定理**，再说明完整模型的对应关系（`02` §3.1 开头） |
| C11 | **加 $\epsilon$ 正则化时 $\epsilon$ 取太大** | 改变了主目标的最优解，费用被"优化"了 | $\epsilon$ 取 $10^{-6}$ 量级，并断言加 $\epsilon$ 前后**费用项之差 < $10^{-6}$ 元**（`02` §6） |
| C12 | **费用只算计划购电费，漏掉紧急/调整/违约** | 🔴 总费用被低估，且表 3 填不出来 | 目标函数写全四项（$C^{total}=C^{plan}+C^{over}+C^{penalty}+C^{emergency}$，式 (25)），并做费用分解瀑布图自查 |

## D. 四级翻车（统计与推断错误）

| # | 翻车做法 | 为什么错 | 正确做法 |
|---|---|---|---|
| D1 | **相关性当因果** | 样本内共动不是因果 | 只能说"共动/同向变动/结构上重合"，禁止"导致""引起"（`06` §1.4） |
| D2 | **只报一个相关系数就下建模决策** | 🔴 同一对变量在不同尺度下差别极大：电价—负载 **池化 0.508 / 日级 0.898 / 去形状后 0.797**；电价—光伏 **池化 +0.028（看似无关）/ 日级 −0.343 / 去形状后 −0.467** | 报**三个尺度**并说明池化值为何误导；据此决定情景生成方式（`06` §1） |
| D3 | **按"看起来无关"而独立抽样电价与光伏** | 🔴 真实结构是**负相关**（光伏大发时电价低）；独立抽样会生成"午间光伏大发同时电价高企"的不可能情景 | 用分块 Bootstrap / Copula 保留相关结构（`05` §2） |
| D4 | **在"单个预报时次内部"按提前期算误差增长** | 🔴 该曲线纯属太阳日循环的构成效应（00:00 时次"提前 24 h"对应夜间，MAE = 0） | 用**跨时次的同目标整点配对**；并说明 lead $k$、$k{+}6$、$k{+}12$、$k{+}18$ 的目标整点集合恒等，构成被自动控制（`06` §2） |
| D5 | **反过来过度批评**："误差随提前期增大全是构成假象" | 🔴 **不成立**：每个时次都覆盖全部 24 个目标整点（白天整点均为 14 个）；逐目标整点配对后误差仍单调增长（白天 14 个中 9 个严格单调） | 结论：提前期效应**为真**，6 h→24 h 约 **2.01×**（白天 2.03×），但倍数随目标整点从 1.00× 到 3.57× 剧烈变化，增速集中在正午 |
| D6 | **只报一个 MAE** | 🔴 全样本 MAE 354.19 kW vs 白天 MAE 694.74 kW，**差 1.96 倍**（夜间零误差时段稀释） | 分别报告两个口径，并说明以白天口径作为误差建模依据（`06` §3.1） |
| D7 | **只看全天聚合 bias 就断言"方向安全"** | 🔴 全天聚合 bias 为负（−8.84 至 −54.94 kW）**不代表风险是单向的**：它只是**上下午两半相互抵消**的结果。按**目标整点**看，0:00 发布的白天 bias 是**双符号结构**——上午 h5…h10 为 **+505/+668/+733/+666/+464/+264 kW**（**高估** → 计划购电偏少 → 触发**紧急购电 5p**）；下午 h11…h18 为 **+7/−261/−502/−688/−802/−761/−574/−307 kW**（**低估** → 计划购电偏多 → 触发**违约 0.5p + 白付计划电费**）。两边都是钱，**不能说"方向是安全的"** | 按**目标整点**复算 bias 的符号与形状，报告上下午的双向风险，并说明全天聚合值是两个方向的抵消量；方向比大小更重要（`06` §3.2、裁定基准 `D9`） |
| D8 | **不做校准检验就假设正态** | 报童用的分位数会系统性偏离 | 至少给 PIT 直方图或 QQ 图；说明是否近似正态（`06` §4） |
| D9 | **季节性靠目测** | "从图上可见季节性"无证据 | 给跨月极差表（平均极差 0.2233 元/kWh）或谐波回归/置换检验（`06` §5.1–5.2） |
| D10 | **只报点估计不给区间** | 无法判断 26.9%（Q1 典型日）与 25.4%（全窗日环状）是否有区别 | 报均值 ± 标准差 + 95% CI（≥20 个种子）（`10` §3） |
| D11 | **把附件 1 当验证集/回测集** | 🔴 附件 1 与附件 2/4 的年内均值剖面**完全一致（相关 = 1.0000）**，用它验证是**循环论证** | 用滚动外测或时间切分，绝不用附件 1 作验证（`06` §5.4） |
| D12 | **把附件 1 当作"典型日的日前预报"（解读 R2）** | 🔴 附件 1 第 4 列表头写"光伏发电**预测**功率"，但数值等于附件 2 **实际**功率的年均值——**它不是预报，是事后平均** | 使用 R2 解读需额外论证，否则被质疑数据泄漏；推荐主方案用 R3（`06` §5.4、`03` §0） |

## E. 五级翻车（呈现与写作错误）

## F. 评审视角的三类判决（自查时用这个标准）

评审在 5–10 分钟内会形成三个判断。**任何一项为"否"，后面都是白费。**

### 判决一："这队读懂题了吗？"

| 触发"否"的信号 | 你的防线 |
|---|---|
| 没有按时标对齐（丢掉 `0:00+1`、错位 1 小时） | C2、C3、C4 |
| 问题 2/3 用了未来信息（数据泄漏） | A3 |
| 把"平均日"当成"某一天"，或把附件 1 当预报 | D11、D12 |
| 引入需求响应/博弈等题目没有的机制 | B7、B8 |

### 判决二："这队算对了吗？"

| 触发"否"的信号 | 你的防线 |
|---|---|
| 单位 kWh / kW 混乱，费用量级离谱 | C1、C12 |
| SOC 越界、跨日断裂、末日掏空 | C6、C7 |
| 只有"求解器说 optimal"，没有独立复算 | `07` §5 三联报告、`10` §6.2 |
| 结果文件结构不合规 | A4 |

### 判决三："这队有没有想法？"

| 触发"是"的信号 | 对应炫技 |
|---|---|
| 给出了最优策略的**形式**（阈值律），不只是数字 | `02` §3 |
| 回答了"是否需要更多预报"，且带**成本侧比较** | `04` §3.3 |
| 每个创新都有**消融证据**与**边界条件** | `10` §1、`08` §6 |
| 主动**修正了自己的结论**（如 2.2× → **受控配对** 2.01×（全样本）/2.03×（白天）） | `06` §2 |
| 局限写得具体，有影响方向与验证路径 | E5 |

> **关键洞察**：判决三的**门槛其实不高**，但**绝大多数队伍根本不尝试**。
> 只要做到 `README` 排行榜的前 6 项，判决三就能拿到"是"。

## H. 使用方式

1. **建模中期**：用 A、B、C 组自查模型与代码（此时改还来得及）；
2. **结果出来时**：用 D 组自查统计推断，E 组自查写作；
