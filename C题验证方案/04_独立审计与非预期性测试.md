> 本文件给出"防自证"的工程规范。核心要求：**验证代码不共用建模代码的费用/约束函数**，
> 且对问题 2–4 必须通过信息泄漏测试。

## 1. 独立审计脚本设计

### 1.1 输入与输出

```
输入：
  原始附件（附件1–4）
  结果文件（`C题代码/result/` 下的 result1/2/3/4-2/4-3.xlsx）
  模型元数据（参数、单位、时标约定）
输出：
  `C题代码/intermediate/audit_report.md`，逐项 PASS/FAIL + 最大残差 + 定位信息
```

### 1.2 审计项与阈值

| 编号 | 审计项 | 计算方式 | 阈值 |
|---|---|---|---|
| A1 | 平衡残差 | res_t = E_t + PV_tΔt + P^d_tΔt + **g_t** − L_tΔt − P^c_tΔt − s_tΔt（**结算平衡必须含紧急购电**；问题 1 时 g≡0） | max\|res\| ≤1e−6 kWh |
| A2 | SOC 递推 | res_t = S_{t+1} − S_t − η_c P^c_tΔt + P^d_tΔt/η_d | max\|res\| ≤1e−6 kWh |
| A3 | SOC 边界 | S_t − [1 200, 10 800] | 越界数 = 0 |
| A4 | 功率边界 | P^c_t, P^d_t − [0, 5 000] | 越界数 = 0 |
| A5 | 充放互斥 | P^c_t·P^d_t | max ≤1e−6 |
| A6 | 周期/终端 | 问题1：S_0−S_144；问题2–4：跨日差 | =0（Q1）/ ≤1e−6 |
| A7 | 非负性 | min(E, P^c, P^d, s, g, Cost) | ≥−1e−6 |
| A8 | 费用复算 | 计划 + 紧急 + 调整 + 违约 | 相对误差 ≤1e−4 |
| A9 | 日期与行数 | **位置式**规则：附件 5 第 j 期（j=0..143）↔ 附件 1 第 j 行 ↔ 附件 2/4 第 j+1 列；断言工作表名、标签**计数**（147/145/144）、`result2/3/4-*` 的日期范围 2025-02-01…12-31（334 行）。**按列名逐一比对不可行**：附件 1 时间列含 60 个时间值 + 84 个字符串，附件 2 表头含 143 个时间值 + 2 个字符串，模板末标签在 `result1` 与 `result2/3/4-*` 上写法不同（`0:00+1-0:10+1` vs `0:00-0:10+1`），且 result2/3/4-* 表头第 43 个单元格有笔误 `7:0-7:10` | 工作表名、标签计数、日期范围逐项相等 |
| A10 | 全天汇总列 | 全天购电量、全天购电费（**不适用于 `result1`**——`result1` 为 145×2 竖表、无全天行） | 与逐时段求和一致（相对）≤1e−4 |

> **A9 的"334 天"只适用于 `result2/3/4-*`**：`result1` 的计划购电量表是 145×2 竖表（144 个时段 + 表头），只有 `result2/3/4-*` 才有 334 个日期行。
> **A1 的 g 不得省略**：附件 5 把"计划购电量"与"紧急购电量"分成**两张表**，**计划量 ≠ 实际供给量**；漏 g 时平衡残差恰等于 g（实测合法结算 g[42]=600 kWh 时残差 600.000 kWh，超 1e−6 容差 6.0e8 倍），补 `+g` 后为 1.49e−13。

### 1.3 审计实现要点

1. **单位断言**：读入时立即把 kW 与 kWh 分开，所有物理量带单位后缀（`_kw`、`_kwh`）；
2. **时标断言**：明确"第 i 个数据点 = 第 i 个 10 min 区间"，模板列按顺序对应；
3. **多方校验**：费用分别用"逐时段求和"和"全天汇总列"两条路径计算；
4. **不信任导出文件**：读回 xlsx 再算一遍，防止写文件错位。**但必须接受一条现实约束**：交付物里只有 **6 个 4 h 聚合充放值**与 **0:00/24:00 两个储电量**，**没有 10 min 粒度的 P_c/P_d**——因此 10 min 级 SOC 递推**只能在模型自己的解上校验**，**不得声称已核验交付物**；对交付物必须另设 **4 h 块级审计**（b = 0..5，块内量均为 4 h 聚合电量）：
   - SOC 块递推：`S_{b+1} = S_b + η_c·Ec_b − Ed_b/η_d`；
   - 块内平衡：`E_b + g_b + PV_b + Ed_b = L_b + Ec_b + s_b`；
   - 边界：`S_b ∈ [1 200, 10 800]`、`Ec_b, Ed_b ∈ [0, 4·P_max]`；
   - 版式（`0:00` 储电量落在 `0:00-4:00` 行、`24:00` 落在 `4:00-8:00` 行；充放电量必须删掉字面量 `⁝` 行并重建 334×6 = 2 004 行）；
5. **失败即阻断**：任一 A1–A7 失败，禁止进入论文写作。

## 2. 对偶与 KKT 验证

### 2.1 对偶目标

- 对 LP：`primal_obj` 与 `dual_obj` 相对差 ≤1e−6；
- 若使用分支定界/MILP：报告 gap = (bound − incumbent)/|incumbent| ≤1e−4。

### 2.2 影子价格解释（问题 1/2）

设 SOC 约束乘子为 μ_t（电池中下一度电的边际价值）。**索引约定以本节为准：μ_t 与时段 t 同槽**（μ_t 为第 t 段 SOC 约束的乘子），与已验证代码一致：

- 充电时段应满足 p_t ≈ η_c μ_t；
- 放电时段应满足 μ_t/η_d ≈ p_t；
- 检查"高价放电、低价充电"与 μ 的时序是否一致。

**注意**：乘子符号依赖求解器约定，先在小规模已知解上标定，再用于全量解释。

### 2.3 交叉求解器

| 求解器 | 用途 |
|---|---|
| HiGHS（scipy.linprog） | 主力，快速迭代 |
| CBC（PuLP）或 Gurobi/COPT | 独立复核目标值与关键决策 |

**通过标准**：目标值相对差 ≤1e−6；若不一致，优先检查容差、缩放与约束符号，而非直接采信某一个。

## 3. 非预期性（信息泄漏）测试

### 3.1 原理

一个合法的在线策略，其 t 时刻决策只能依赖 ≤t 的信息。测试方法是**替换未来数据，观察过去决策是否改变**。

### 3.2 测试协议

```
1. 取原始数据 D，跑策略，记录 t 时刻前的全部决策序列 X_{≤t}；
2. 构造扰动数据 D'：
   - 保持 t 时刻及之前的数据完全相同；
   - 将 t 时刻之后的数据做任意扰动（如 ×2、加噪声、置换）；
3. 用同一策略在 D' 上重跑，记录 X'_{≤t}；
4. 断言 X_{≤t} == X'_{≤t}（数值容差 ≤1e−6）。
```

### 3.3 本题实施点

**必须按已声明的信息结构（R1/R2/R3，见 `03` §2.1）分列定义用例**：题面问题 2 的 0:00 计划，就是"根据附件 1 的电价和附件 2 的数据"制定的**全天 144 维向量**，因此"扰动 0:00 之后的 L/PV 真值"**必然**改变计划——按这种设计出来的 Q2 用例是**必然误报**，不构成泄漏证据。

| 问题 | 测试对象 | 扰动的"未来" |
|---|---|---|
| Q2（**R1 完美信息：只做跨日测试**） | 第 d 天的 0:00 计划购电量 | 扰动**第 d 天整日**的 L、PV 真值，断言 **d 之前各日的计划逐位不变**（同日 144 维计划本身允许改变，不算泄漏） |
| Q2（R2/R3：日内测试） | 第 d 天的 0:00 计划购电量 | 只扰动**更晚发布**的预报与**未来实际值**（R2 下为附件 1 之外的信息，R3 下为 0:00 之后发布的预报） |
| Q3（**R3 日内测试**） | 6:00 调整量 | 只扰动**更晚发布**的预报（12:00/18:00）与**未来实际值**，且**必须保留**"发布时刻 = t 的那条预报"不被扰动 |
| Q3（R3） | 12:00 / 18:00 调整量 | 同上（对应时刻之后） |
| Q4 | Q2/Q3 的价格相关决策 | 未来电价（按 R1/R3 分别定义，规则同上） |

### 3.4 特别注意

- **附件 3 的 18:00 预报跨日**：题面明说 18:00 发布的是"**未来 24 小时**"预报，覆盖次日 0:00–17:00，**跨日部分的使用是合法的**（见 `C题炫技方向/08`）；真正的泄漏是使用**附件 2 的次日实际值**或**更晚发布**的预报。若前瞻越过 24:00，应声明为 look-ahead 而**不是** leakage；
- **滚动 MPC**：后一次调整覆盖前一次时，已被执行区间的决策不得重算；
- **场景抽样**：随机种子只影响未来情景，不得影响已实现时段的决策；
- **结果表**：计划表与调整表的时段归属要能追溯，避免"用后验最优冒充在线策略"。

## 4. 与求解器输出无关的"决策合理性"检查

除数学残差外，做以下定性检查并解释：

1. 低价时段充电、高价时段放电（检查能量加权充放电价差 >0，典型日充电均价 < 放电均价）；
2. 储能不会在正价差方向上长期闲置；
3. 紧急购电只出现在供应缺口时段；
4. 弃光只出现在盈余且电池无法消纳的时段（**平均日最优弃光 = 0**；实际日序列 72/334 天弃光 > 0）；
5. 调整方向与新预报一致（新预报变差 → 增加计划/调整购电）；
6. 费用分解（计划/紧急/调整）占比合理，无异常大项。

**异常处理**：若某条不成立，先怀疑模型/数据，不急于写"策略特殊"。

## 6. 常见审计失败模式

| 现象 | 可能原因 |
|---|---|
| 平衡残差整体偏移一个常数 | 时标错位、kW/kWh 混用、模板列错位 10 min |
| SOC 末值不等于初值 | 周期约束漏写、跨日递推错误 |
| 费用比求解器目标低 | 审计漏项（调整/紧急费用）或口径不一致 |
| 费用比目标高 | 对"计划费是否退还"的口径与模型不一致。**本题主口径下，`E_adj<E_plan` 的违约分支在最优解中永不活跃**——成本对 E_adj 的偏导为 −0.5p<0，减少调整量只会更省钱，故该分支只能作为**对照口径**出现，不能出现在主结果里 |
| 决策对"未来扰动"敏感 | 代码中使用了完整序列的信息（泄漏） |
| HiGHS 与 Gurobi 差异大 | 数值缩放、容差、约束冗余或模型非凸书写 |
